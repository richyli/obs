Harman's Single Factor Test — JASP 操作範例

Harman's Single Factor Test（哈曼氏單因子檢定）邏輯非常簡單粗暴：

「如果我把所有的題目硬湊成『一個因子』，這個因子解釋的變異量如果不超過 50%，那就代表沒有嚴重的共同方法變異（CMB Common method bias）。」

CFA Marker Variable Technique 在學術上更嚴謹、更高級，但因為 Harman's Test 太有名了，很多審稿人還是會習慣性地要求看一下。

以下是在 JASP 執行 Harman's Test 的標準 SOP：

一、JASP 操作 SOP

第一步：開啟 EFA 模組

  1. 點選上方選單的 Factor
  2. 選擇 Exploratory Factor Analysis (EFA)

第二步：放入變數（大雜燴）

把模型中所有「原本要分析」的題目都丟進去。

  • 放入：例如 Stress (Work, Family, Money)、Support (1-3)、Mental (1-3)、Physical (1-3)
  • 不要放：被刪除的題目（如 Stress_Traffic）
  • 不要放：標記變數（Blue 系列）。因為 Harman's 是要檢查「主要變數」之間有沒有糾纏，不需要 Marker 介入

第三步：關鍵設定（重點）

下方的設定面板，依序調整：

  1. Rotation（旋轉）：選 None（這非常重要！絕對不能旋轉）
  2. Number of factors（因子數量）：選 Manual（手動），設定為 1（強迫只能萃取一個因子）
  3. Extraction method（萃取法）：傳統用 Principal Component Analysis (PCA)；JASP 也可選 Principal Axis Factoring 或 Maximum Likelihood
  4. Base Decomposition on（分解基礎）：點選 Correlation matrix

第四步：判讀結果（一秒定生死）

看右側 Factor Loadings 表格下方，或單獨的 Variance explained / Factor Characteristics 表格（視 JASP 版本而定）的 Total Variance Explained 或 Proportion var. 欄位。

  • 判準：
  • ✅ 通過（< 50%）：「共同變異」沒有壟斷數據，CMB 不嚴重
  • ❌ 失敗（> 50%）：有一個巨大的背後靈（可能是填答習慣）控制了超過一半的分數

二、案例一：通過（35.2%）

假設 JASP 跑出來的結果，那個因子解釋了 35.2% 的變異量。學術寫作範例：

「此外，本研究亦採用 Harman's 單一因子檢定（Harman's Single Factor Test）進行共同方法變異之檢測。將所有測量題項納入探索性因素分析（EFA），採用主成分分析法（PCA）且不進行旋轉（Unrotated），限制萃取單一因子。分析結果顯示，該單一因子僅解釋了總變異量的 35.2%，未超過 50% 之門檻（Podsakoff et al., 2003）。此結果與標記變數法之發現一致，再次證實共同方法變異並非本研究之主要威脅。」

這張表是 Harman's Test 結果。看 Factor Characteristics 的 Proportion var.：0.522（即 52.2%）。

🚨 結果判讀：發生了什麼事？

根據 Podsakoff et al. (2003) 標準，這個數字應該要 小於 0.50（50%） 才算通過。本例 52.2%，稍微超過了門檻——學術上叫「邊緣不通過（Marginally Failed）」。如果只看這個測試，會判定有 CMB 風險。

但是！請不要驚慌！ ✋ 這反而是一個展現 CFA Marker Variable Technique 重要性的絕佳機會。

為什麼會這樣？（科學解釋）

  1. Harman's Test 的老毛病：它出了名的「太嚴苛」且「不準確」。只要變數之間相關性很高（例如 Support 跟 Mental、Physical 本來就應該高度相關），就會誤判為 CMB
  2. 真實的關聯 vs. 誤差：模型中社會支持、心理健康、生理健康三者本身在理論上就有很強的相關性（都在 0.6 ~ 0.7 左右）。Harman's Test 把這些「好的相關」也當成了「壞的污染」，所以才會爆衝到 52.2%

📝 論文該怎麼寫？（轉危為安的寫法）

有 Marker Variable 作為最強防禦武器，可以這樣寫：

「本研究首先採用 Harman's 單一因子檢定（Harman's Single Factor Test）。結果顯示，單一因子解釋變異量為 52.2%，略高於 50% 之門檻，暗示可能存在共同方法變異之風險。

然而，鑑於 Harman's 檢定缺乏統計敏感度且容易因構念間的真實高相關而產生誤判（Podsakoff et al., 2003），本研究進一步採用更為嚴謹的 Lindell & Whitney (2001) 標記變數法（Marker Variable Technique） 進行確認。

標記變數分析結果（見前表）顯示，標記變數與主要構念間的相關係數極低（$r < 0.1$）且未達顯著水準。此結果證實，Harman's 檢定中較高的解釋變異量主要源自構念間的實質理論關聯，而非共同方法變異。因此，綜合判斷本研究受共同方法變異偏差影響之程度在可接受範圍內。」

四、💡 專家提示：為什麼還是推薦用 Marker Variable？

雖然 Harman's Test 很簡單，但有兩個致命傷：

  • 對 Formative 變數不友善：EFA 的數學假設是 Reflective 的（因子導致題目）。把互不相關的 Stress 題目硬丟進去跑 PCA，數學邏輯上其實有點怪怪的（雖然實務上大家還是照做）
  • 靈敏度低：通常除非數據爛到不行，否則很容易就小於 50%；反之像本例 52.2% 也常因實質相關被誤判

結論：Lindell Exercise（Marker Variable）才是「王牌」。Harman's Test 只是當作「買保險」，放在論文裡讓老派審稿人閉嘴用的。建議兩個都寫，防禦力點滿！
