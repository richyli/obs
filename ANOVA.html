ANOVA（Analysis of Variance，變異數分析）

定義：比較三個或更多組均值是否有顯著差異的統計方法。透過分解總變異為「組間變異」與「組內變異」，計算 F 統計量判斷差異是否超過偶然水準：

$$F = \frac{MS_{between}}{MS_{within}}$$

來源：Sir Ronald Fisher 於 1920 年代發展，是實驗設計研究的核心統計工具（Fisher, 1925）。

常見形式： - One-way ANOVA：單因子，比較多組均值 - Two-way ANOVA：雙因子，同時分析主效應與交互效應 - ANCOVA：加入協變量控制（如 pre-test 分數） - Repeated-measures ANOVA：同一受試者跨條件比較

方法說明

目的

  • 主要研究目的：檢驗多組均值是否存在統計上顯著差異，並量化主效應與交互效應的相對貢獻（Mainardi, 2022；Mainardi 2022 Fundamental Concepts）
  • 次要用途：因子實驗設計的標準分析工具；事前檢定力分析的基礎模型

流程

  1. 確認因變量為連續、自變量為類別（單因子或多因子）
  2. 檢視假設：常態性（Shapiro–Wilk）、變異數同質性（Levene's test）、獨立性
  3. 計算 $SS_{total} = SS_{between} + SS_{within}$，求 F 統計量
  4. 顯著時執行 post-hoc 比較（Tukey HSD、Bonferroni、Scheffé）
  5. 報告 $\eta^2$ 或 $\omega^2$ 效果量；繪製交互效應圖（two-way 情境）

適用範圍

  • 適用：3+ 組獨立樣本均值比較；2×2、2×3 因子設計；前測–後測 between-within 混合設計
  • 不適用：兩組比較（用 t 檢定）；類別因變量（用 logistic regression / chi-square）；嚴重違反常態性與變異數同質（改用 Welch's ANOVA、Kruskal–Wallis）
  • 樣本規模建議：每組至少 20–30；2×2 設計建議 N ≥ 80 達到 power 0.8 偵測中等效應（暫無 wiki/ 資料）
  • 資料類型要求：連續因變量；類別自變量（含因子實驗設計）

單因子變異數分析（ANOVA）**

  • 目的：
    • 檢測推薦類型（獨立變數，兩組）是否顯著影響三個依變數的平均值。
  • F 值的解釋：
    • F 值越大，說明組間變異相對於組內變異越大，表示推薦類型對依變數的影響越顯著。
  • 顯著性檢驗 (p 值)：
    • p 值小於 0.05，表示推薦類型對依變數的影響具有統計顯著性。

ANOVA 與迴歸的區別

ANOVA（變異數分析）與迴歸分析都是用來研究變數之間關係的重要統計方法，但它們在目的、變數類型、分析焦點與應用場景上有明顯不同。

1. 目的

  • ANOVA（變異數分析）：

    • 用於比較兩組或多組的平均數是否存在顯著差異。
    • 主要目標：判斷不同組別之間的均值是否有統計顯著的差異。
    • 範例：測試三種教學方法對學生成績的影響是否不同。

    • 迴歸分析：

    • 用於探討一個因變數（dependent variable）與一個或多個自變數（independent variables）之間的關係。

    • 主要目標：預測或解釋因變數，並量化自變數的影響。
    • 範例：預測房價（因變數），根據房屋面積和地點（自變數）。

2. 變數類型

  • ANOVA：
    • 自變數是類別變數（categorical variable，例如「教學方法」分為三組）。
    • 因變數是連續變數（continuous variable，例如學生分數）。
  • 迴歸分析：
    • 自變數可以是連續變數（如收入、年齡）或類別變數（如性別）。
    • 因變數是連續變數（如銷售額、溫度）。

3. 數學框架

  • ANOVA：

    • 分析因變數總變異（total variance）中有多少是來自於：
      1. 組間變異（Between-Group Variance）：不同組別的均值差異。
      2. 組內變異（Within-Group Variance）：同組內個體的差異。
    • 使用 F 統計量檢驗組間變異是否顯著大於組內變異。

    • 迴歸分析：

    • 通過線性方程描述自變數和因變數之間的關係： Y=β0+β1X1+β2X2+⋯+ϵY = \beta_0 + \beta_1X_1 + \beta_2X_2 + \dots + \epsilon

    • 目的是估計參數（如 β1,β2\beta_1, \beta_2），並檢驗每個自變數對因變數的影響是否顯著。

4. 假設檢定

  • ANOVA：

    • 虛無假設（H0H_0）：所有組別的均值相等。
    • 備擇假設（HaH_a）：至少有一組的均值不同。
    • 範例：假設 H0:μ1=μ2=μ3H_0: \mu_1 = \mu_2 = \mu_3。

    • 迴歸分析：

    • 虛無假設（H0H_0）：每個自變數的回歸係數為 0（即該變數對因變數沒有影響）。

    • 備擇假設（HaH_a）：至少有一個回歸係數不為 0。
    • 範例：假設 H0:β1=0H_0: \beta_1 = 0。

5. 輸出與解釋

  • ANOVA：

    • 輸出 F 值和 p 值。
    • 如果 p 值小於顯著水準（例如 0.05），則拒絕虛無假設，表示組間平均數有顯著差異。
    • 如果差異顯著，可進一步進行事後檢定（如 Tukey's HSD）來確定哪一組均值不同。

    • 迴歸分析：

    • 輸出每個自變數的回歸係數（β\beta）、標準誤（Standard Error）、t 值和 p 值。

    • 解釋自變數對因變數的影響方向（正或負）和影響程度。

6. 應用場景

  • ANOVA：

    • 比較多組均值差異。
    • 範例：測試不同廣告形式（如視覺型、文字型）對消費者點擊率的影響。

    • 迴歸分析：

    • 預測或量化因變數與多個自變數的關係。

    • 範例：分析廣告預算（自變數）如何影響銷售額（因變數）。

7. 擴展方法

  • ANOVA：

    • 單因子 ANOVA：只有一個自變數。
    • 雙因子 ANOVA：有兩個自變數，可檢測交互作用。
    • 多變量 ANOVA（MANOVA）：分析多個因變數。

    • 迴歸分析：

    • 多元迴歸：多個自變數。

    • 邏輯迴歸：用於二元因變數（如購買與否）。
    • 非線性迴歸：適用於非線性關係。

8. ANOVA 與迴歸的交集

ANOVA 可以看作迴歸的一種特例：

  • 當自變數是類別變數時，ANOVA 等價於對這些類別變數進行迴歸分析（例如使用虛擬變數）。

9. 重點區別

項目 ANOVA 迴歸分析
主要目標 比較多組平均數 預測或解釋因變數
自變數類型 類別變數 連續或類別變數
因變數類型 連續變數 連續變數
輸出 F 值與 p 值 回歸係數、R²、t 值與 p 值
主要應用 分析群體均值差異 分析變數之間的線性關係

總結

  • ANOVA：適合用於檢測不同組別之間的均值是否存在顯著差異。
  • 迴歸分析：適合用於預測因變數，並量化自變數對因變數的影響。

選擇使用 ANOVA 或迴歸分析，取決於研究目標和數據特性。如果自變數是類別變數且關注均值差異，選擇 ANOVA；如果需要分析多種自變數對因變數的影響，則選擇迴歸分析。

10. ANOVA 作為 GLM 特例

ANOVA 並非獨立的統計家族，而是 General Linear Model（GLM）在「自變量為類別」情境下的特例。把類別變量編成 dummy（或 effect coding），ANOVA 的 $F$ 檢定等於對「所有 dummy 係數同時為 0」的迴歸 $F$ 檢定。這也是現代統計軟體（Lavaan、JASP、seminr）內部把 ANOVA 統一以 lm() / glm() 實作的原因。實務影響：

  • 不平衡設計：類別組樣本數不一致時，two-way Anova 的 Type I / II / III sum of squares 會給出不同結果；GLM 觀點直接揭示這是「設計矩陣非正交」造成的多重解
  • 連續 × 類別交互：把連續變量加入 ANOVA 即得到 ANCOVA，再進一步即一般迴歸，沒有統計學上的斷層

11. Post-hoc 比較家族

當整體 $F$ 顯著且組數 ≥ 3，需執行 post-hoc 比較確定差異所在。常見選項與適用情境：

方法 控制錯誤 特點 適用
Bonferroni family-wise（FWER） 最保守 比較數少（< 10）
Tukey HSD FWER（all pairwise） 平衡保守與 power 所有兩兩比較
Scheffé FWER（任何對比） 最保守、最彈性 事後決定 contrast
Dunnett FWER（vs. control） 比 Tukey 高 power 多組對單一控制組
BH FDR 高 power 探索式、多比較

ANOVA 主流期刊習慣 Tukey HSD；探索性研究或基因表達等大量比較情境改用 BH（FDR 控制）。

12. 違反假設時的替代方案

違反 替代
變異數不等 Welch's ANOVA、Brown–Forsythe
嚴重非常態 Kruskal-Wallis test（無母數版本）
同一受試者重複測量 one-way Anova Repeated measures、Mixed-effects model
多個依變量 MANOVA、Multivariate GLM

13. 效果量與 Power

只報 $F$ 與 $p$ 已不被多數頂刊接受。報告：

  • $\eta^2$：$SS_{between}/SS_{total}$（總變異被組別解釋的比例）
  • $\omega^2$：對小樣本偏誤更小，建議優先使用
  • partial $\eta^2$：多因子設計時排除其他因子變異後的偏比例

Cohen（1988）建議基準：小 0.01、中 0.06、大 0.14（partial $\eta^2$）。事前 power 分析以 G*Power 或 JASP_ANOVA_effect_size 計算所需樣本（Survey Experiment Effect Size Benchmarks）。
