JASP 統計分析講義（學生指南 2025）

本講義改寫自 Goss-Sampson, M. A. (2025). Statistical Analysis in JASP: A Guide for Students (7th Ed., JASP v0.19.3). Licenced as CC BY 4.0.

本講義定位：以 JASP 軟體操作為主軸；統計理論細節（公式推導、歷史脈絡、研究範例）一律連回 social_science_statistics_book 與 wiki 既有概念 note。

配套圖片：所有 JASP 截圖以整頁渲染存放於 wiki/img/jasp_lecture/，每篇 note 嵌入對應頁面。

官方資源：JASP 下載 https://jasp-stats.org/ ｜ 範例資料集 https://osf.io/bx6uv/

目錄

Part 1. JASP 環境與資料處理

  • JASP_environment — JASP 介面、預設設定、深淺主題
  • JASP_data_file_types — 支援的資料格式（.jasp / .csv / .xlsx / .sav 等）
  • JASP_analysis_menu — 分析選單地圖（T-Tests / ANOVA / Regression / Frequencies / Factor / Meta-Analysis）
  • JASP_data_handling — 變數型態（nominal / ordinal / continuous）、編碼、標籤
  • JASP_data_filtering — 資料篩選與隱藏類別
  • JASP_data_editing — 直接編輯儲存格、與外部 Excel 同步
  • JASP_data_transformation — 計算欄位、log/sqrt 轉換
  • JASP_split_files — 依分組變數切分敘述統計

Part 2. 敘述統計

  • JASP_descriptive_statistics — Descriptives 主面板總覽
  • JASP_central_tendency — 平均、中位數、眾數
  • JASP_dispersion — SD、SE、變異數、MAD、IQR、CV
  • JASP_confidence_intervals — 95% CI 計算與報告
  • JASP_quartiles — 四分位數與百分位
  • JASP_skewness_kurtosis — 偏態、峰度與其 z 檢定

Part 3. 視覺化

  • JASP_distribution_plots — 直方圖、密度、dot、interval plot
  • JASP_boxplots — 箱形圖元素拆解
  • JASP_QQ_plots — Q-Q 圖判讀
  • JASP_raincloud_violin_plots — Violin、jitter、Raincloud
  • JASP_scatter_heatmap_plots — 散佈圖、tile heatmap、Pareto、Likert
  • JASP_editing_plots — 圖形編輯與輸出

Part 4. 資料完整性與假設檢查

  • JASP_outliers — 離群值偵測、保留 / 刪除 / 修正 / winsorize
  • JASP_bias — 樣本偏誤類型
  • JASP_normality_test — Shapiro-Wilk + skew/kurt z 檢定
  • JASP_levene_test — 變異數同質性檢定
  • JASP_homoscedasticity — 殘差同質性
  • JASP_central_limit_theorem — 中央極限定理在 JASP 假設檢查中的角色

Part 5. 效應量與單樣本檢定

  • JASP_effect_size — JASP 各檢定支援的效應量總表
  • JASP_one_sample_ttest — 單樣本 t 檢定
  • JASP_binomial_test — 二項式檢定
  • JASP_multinomial_test — 多項式檢定
  • JASP_chisquare_goodness_of_fit — 卡方適合度檢定

Part 6. 兩組比較

  • JASP_independent_ttest — 獨立樣本 t 檢定
  • JASP_welch_correction — Welch 校正
  • JASP_mann_whitney — Mann-Whitney U 檢定
  • JASP_paired_ttest — 配對樣本 t 檢定
  • JASP_wilcoxon — Wilcoxon 符號等級檢定

Part 7. 相關與迴歸

  • JASP_correlation — Pearson 相關
  • JASP_nonparametric_correlation — Spearman、Kendall's tau
  • JASP_coefficient_determination — R² 解釋變異
  • JASP_spurious_correlation — 偽相關警示
  • JASP_regression_overview — 迴歸總覽與假設
  • JASP_sums_of_squares — SST / SSM / SSR
  • JASP_simple_regression — 簡單線性迴歸
  • JASP_multiple_regression — 多元迴歸
  • JASP_regression_entry_methods — Enter / Backward / Forward / Stepwise / Hierarchical
  • JASP_logistic_regression — 邏輯迴歸
  • JASP_confusion_matrix — 混淆矩陣、敏感度、特異度

Part 8. ANOVA 家族

  • JASP_oneway_ANOVA — 單因子獨立 ANOVA
  • JASP_familywise_error — 家族錯誤率
  • JASP_ANOVA_contrasts — 計畫對比（Deviation / Simple / Helmert / Polynomial 等）
  • JASP_post_hoc_tests — Tukey / Bonferroni / Holm / Scheffé / Sidak / Games-Howell / Dunnett / Dunn
  • JASP_ANOVA_effect_size — η²、partial η²、ω²
  • JASP_kruskal_wallis — Kruskal-Wallis 無母數 ANOVA
  • JASP_RMANOVA — 重複量數 ANOVA
  • JASP_sphericity — 球形性與 Mauchly 檢定、Greenhouse-Geisser / Huynh-Feldt 校正
  • JASP_friedman_test — Friedman 重複量數無母數
  • JASP_ANCOVA — 共變數分析
  • JASP_twoway_independent_ANOVA — 二因子獨立 ANOVA
  • JASP_twoway_repeated_ANOVA — 二因子重複量數 ANOVA
  • JASP_mixed_factor_ANOVA — 混合因子 ANOVA
  • JASP_simple_main_effects — 簡單主效應
  • JASP_interaction_effects — 交互作用判讀

Part 9. 卡方關聯與 Meta 分析

  • JASP_chisquare_association — 卡方獨立性／關聯性檢定
  • JASP_cramers_v — Cramer's V、Phi 效應量
  • JASP_odds_ratio — 勝算比
  • JASP_pearson_residual — 標準化殘差作為 post hoc
  • JASP_meta_analysis — Meta-analysis 模組
  • JASP_heterogeneity — Q、tau²、I²、H² 異質性指標
  • JASP_forest_plot — 森林圖
  • JASP_funnel_plot — 漏斗圖與發表偏誤
  • JASP_effect_size_computation — 從各種統計量計算 ES + SE

Part 10. 頻率派概念與檢定選擇

  • JASP_hypothesis_testing — 虛無假設、對立假設、α、p
  • JASP_type_I_II_errors — 第一型、第二型錯誤
  • JASP_pvalue — p 值的正確詮釋
  • JASP_parametric_nonparametric — 母數 vs 無母數檢定對照
  • JASP_test_selection — 「我該用哪個檢定？」流程圖
  • JASP_data_layout — Excel 資料排版範例（依檢定方法）

教學使用建議

  1. 零基礎讀者：先讀 Part 1（環境）→ Part 2（敘述）→ Part 4（假設檢查）→ Part 10（頻率派概念）建立全局觀。
  2. 直接做實驗：依研究設計到 JASP_test_selection 找對應檢定，跳到該 note 跟著操作。
  3. 報告撰寫：每篇檢定 note 末段都附 APA 報告範本。
  4. 與既有手冊搭配：操作步驟看本講義；公式、符號、跨領域研究範例請查 social_science_statistics_book。
