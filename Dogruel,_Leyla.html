Dogruel, Leyla

#scholar　#algorithm_literacy　#algorithm_awareness　#media_literacy　#scale_development　#gender_byline_bias

Dogruel, Leyla

機構：Johannes Gutenberg University Mainz（JGU Mainz, Germany） 研究領域：演算法素養（algorithm literacy）、演算法意識（algorithm awareness）、媒體素養與數位素養、量表開發（IRT/Rasch）、性別 byline 偏見與作者公信力

主要學術貢獻與典範

  • 提出 algorithm literacy 的四維概念框架：兩個認知維度（awareness and knowledge / critical evaluation）與兩個行為維度（coping behaviors / creation and design），整合 media literacy、digital literacy、new media literacy、privacy literacy 四個既有素養傳統，並以金字塔式依賴關係（缺乏 awareness → 無法 evaluate → 無法 cope → 無法 create）統整；以 33 位德國成年網民半結構訪談支撐維度的具體展現（Dogruel, 2021）。
  • 系統化檢討演算法素養的四項實證測量挑戰：時間敏感性、自陳偏誤、技能光譜不平等、跨領域同步測量困難，為後續量化操作奠基（Dogruel, 2021）。
  • 與 Masur、Joeckel 以 item response theory（IRT）/ Rasch model 開發並驗證首套廣義、跨情境的演算法素養量表，鎖定兩個認知維度——awareness of algorithm use 與 knowledge about algorithms——經雙研究（Study 1 $N=331$、Study 2 $N=1{,}041$ 德國配額樣本）縮為各 11 題的兩分量表，person separation reliability awareness $.86$、knowledge $.80$，並以三任務情境的效標效度證明量表能預測具體演算法行為（Dogruel et al., 2022）。
  • 指出 awareness 題項較 knowledge 題項更具時間敏感性，呼應其概念化文章對「演算法素養隨技術演進而變動」的警示（Dogruel et al., 2022）。
  • 與 Joeckel、Wilhelm 以兩個德國實驗（Study 1 $N=493$、Study 2 $N=1{,}216$）檢驗性別 byline 是否影響讀者對性別平等議題新聞的評估：單純 byline 標示未觸發 gender byline bias，加入作者照片後出現弱偏見；更發現女性作者在特定情感規範違反情境（anger norm）下被評為較高公信力，並透過公信力中介正向提升閱讀意願——以正負效果相互抵消解釋過往文獻的不一致（Dogruel et al., 2023）。

核心觀點

  • 「傳播研究多聚焦演算法對公共傳播的效果，卻較少系統性研究使用者如何理解、評估、應對演算法；algorithm literacy 須以跨認知—行為雙軸的整合框架界定」（Dogruel, 2021）。
  • 「演算法素養須以廣義、跨情境、經驗證的量表測量；題目應指向不同使用情境而非綁定單一平台，並以 Rasch 參數恆定性確保跨樣本與跨時間可比較」（Dogruel et al., 2022）。
  • 「byline 性別偏見並非單向消失，而是取決於情境與性別線索的顯著度；正向與負向效果可相互抵消，造成文獻結果的不一致」（Dogruel et al., 2023）。

  • Algorithm literacy comprises four dimensions cognitive evaluation coping creation
  • Algorithm awareness varies systematically by Internet use domain
  • Algorithm literacy depends on prior media literacy in cumulative process
  • Algorithm coping strategies span privacy result and activism actions
  • Time sensitivity is core challenge for algorithm literacy measurement
  • Self-report measurement of algorithm literacy faces validity threats
  • Older users feel helpless with algorithmic curation reverting to non-use
  • Algorithm literacy consists of two cognitive dimensions awareness and knowledge
  • Item response theory yields a Rasch scale of two 11-item subscales
  • Both algorithm literacy subscales show good reliability and convergent validity
  • Algorithm literacy predicts correct decisions in task-oriented scenarios
  • Awareness items are more time-sensitive than knowledge items
  • gender byline alone does not trigger reading intention bias in gender equality articles
  • adding author photo activates weak gender byline bias against women
  • female byline increases perceived credibility in anger norm violation context
  • positive and negative byline effects cancel out explaining inconsistent literature
