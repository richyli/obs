VS Code 安裝＋串接 Claude Code：一步一步照做

這是一份手把手安裝指南。前面你看過「會動手的 AI」能做什麼，這頁教你怎麼在自己的 Windows 電腦上把它裝起來、開始用。零基礎也能照著做完。
⚠️ 裝之前先確認一件事：公務電腦要安裝軟體，務必先確認機關資訊單位的政策。有些單位禁止自行安裝、或有指定的核可工具。這份指南適合個人電腦，或機關已核可的環境。

🧩 你會裝到哪些東西？先看全貌

Claude Code 要跑起來，需要三塊拼在一起。先有個概念，等一下就不會迷路：

要裝的東西是什麼為什麼要它
VS Code微軟出的免費程式編輯器Claude Code 的「家」，提供圖形介面
Node.js一個執行環境（附帶 npm 安裝工具）Claude Code 是靠它安裝與執行的
Claude Code會動手的 AI 本體主角。分「命令列 CLI」與「VS Code 擴充功能」兩種介面
💡 你還需要一個 Claude 付費帳號（Pro、Max、Team 或 Enterprise 任一種）。不需要 API 金鑰，直接用帳號登入即可。

📝 完整安裝五步驟（Windows）

1安裝 VS Code

到官網 code.visualstudio.com 下載 Windows 版，一路「下一步」裝完。
建議勾選安裝時的「加入 PATH」與「在資料夾按右鍵用 Code 開啟」兩個選項，之後比較好用。
版本要求：VS Code 1.98.0 以上（新下載的都符合）。

2安裝 Node.js

到 nodejs.org 下載 LTS 版（左邊那顆、寫著「建議多數使用者」的綠色按鈕），一路裝完。
裝完開一個新的命令提示字元（開始選單搜尋「cmd」或「PowerShell」），輸入下面兩行確認裝好了：
node -v
npm -v
✅ 如果各自跳出一組版本號（例如 v20.11.0、10.2.4），代表 Node.js 裝好了。

3用 npm 安裝 Claude Code

在同一個命令視窗，輸入這行安裝 Claude Code 本體：
npm install -g @anthropic-ai/claude-code
⚠️ 不要在前面加 sudo（Windows 本來就不用，加了反而出問題）。裝的時候會跑一陣子，正常。
裝完，輸入這行做健康檢查：
claude doctor
✅ 它會檢查你的環境並回報狀態，看到綠色的勾勾就沒問題。

4在 VS Code 裝 Claude Code 擴充功能

打開 VS Code，按 Ctrl+Shift+X 打開「擴充功能」面板，搜尋 「Claude Code」（作者是 Anthropic），按安裝。
裝好後如果沒出現，從命令面板（Ctrl+Shift+P）執行 Developer: Reload Window 重新載入一次。
💡 這個擴充功能自帶一份聊天面板要用的 Claude；第 3 步裝的 CLI 則是讓你能在 VS Code 的終端機裡直接打 claude 指令。兩個都裝，功能最完整。

5登入，開始用

在 VS Code 裡，點編輯器右上角的火花圖示（Spark），或視窗右下角狀態列的 ✱ Claude Code，打開 Claude 面板。
第一次會出現登入畫面，點登入，瀏覽器會跳出授權頁，用你的 Claude 付費帳號完成授權，回到 VS Code 就登入好了。
✅ 裝完了！現在你可以：選一段文字問它、用 @檔名 讓它讀某個檔、叫它改檔（它會先給你看修改對照、你同意才動手）。

🎯 裝好後，先試這三件事

① 讓它讀一個檔：在聊天框輸入 @ 接檔名（例如 @報告.docx 幫我摘要三個重點），它會讀那個檔回答你。
② 讓它比對兩個檔：把兩份文件放進同一個資料夾用 VS Code 開啟，叫它「把這兩份並排逐條比對，列出差異」。
③ 審核它的修改：叫它改一個檔，它會顯示「原本 vs 建議」的並排對照，你可以接受、拒絕、或直接改——它動手前一定先問你。

⌨️ 常用快捷鍵（Windows）

快捷鍵做什麼
Ctrl+Esc在「編輯器」與「Claude 聊天框」之間切換游標
Alt+K把目前選取的檔案／行號，以 @-提及插進聊天框
Ctrl+Shift+Esc開一個新對話（新分頁）
Shift+Enter聊天框內換行（不送出）
Ctrl+`開／關 VS Code 內建終端機（可在裡面打 claude）

🔐 三個許可模式：讓它多自動、多受控

模式行為適合
Manual（手動）改檔前、跑指令前都先問你新手、處理重要檔案——最安全，建議先用這個
Plan（計畫）先寫出「打算怎麼做」讓你審核，同意才動手複雜任務、想先看它的計畫
Edit automatically（自動編輯）直接改，不問你已經很熟、且是可還原的環境
⚠️ 公務用途強烈建議停在 Manual 模式：每個動作它都先問你、你看過再點頭，才不會發生「它自己改了你沒看到的檔」。點聊天框底部的模式指示器就能切換。

🆘 常見問題排除

  • 裝完擴充功能沒看到火花圖示：先打開一個檔案（只開資料夾不夠），圖示才會出現在編輯器右上角；或按右下角狀態列的 ✱ Claude Code。還是沒有就 Developer: Reload Window 重載。
  • 終端機打 claude 說找不到指令：擴充功能不會自動把 claude 加到系統路徑，要確認第 3 步的 CLI 有裝成功（npm install -g @anthropic-ai/claude-code）。
  • 一直要我登入：從命令面板執行 Developer: Reload Window；若還是不行，試著在終端機打 claude 用 CLI 登入一次。
  • 跟其他 AI 擴充衝突：暫時停用 Cline、Continue 等其他 AI 擴充，重載 VS Code。
  • 公司電腦裝不了：多半是權限或政策限制，找資訊單位確認；或改用 Claude Desktop、網頁版等免安裝的方式。

🐧 進階：更穩定的 WSL 安裝法（選讀）

上面五步驟對多數人已經夠用。如果你之後要做比較重的開發、或遇到路徑相關的怪問題，Windows 官方更推薦的是在 WSL（Windows 裡的 Linux 環境）裡裝——比較穩，但步驟多、門檻高，不熟的人先用上面的方法就好。

👉 點開看 WSL 完整安裝流程
① 啟用 WSL：以系統管理員開 PowerShell，執行：
wsl --install

重開機後驗證：wsl --list --verbose。

② 裝 Ubuntu：到 Microsoft Store 搜尋並安裝 Ubuntu 22.04 LTS，首次開啟時建立使用者帳號，然後更新：
sudo apt update && sudo apt upgrade -y
sudo apt install build-essential curl git wget unzip -y
③ 用 NVM 裝 Node.js（在 WSL 終端機裡）：
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
nvm install --lts
nvm use --lts
nvm alias default node
④ 裝 Claude Code（一樣不要加 sudo）：
npm install -g @anthropic-ai/claude-code
claude doctor
⑤ VS Code 接 WSL：在 VS Code 裝「WSL」擴充功能，左下角綠色角落按鈕選「Connect to WSL」，之後在 WSL 環境裡開資料夾、開終端機打 claude 即可。
WSL 的好處是有一個乾淨的 Linux 環境，避免 Windows 路徑造成的麻煩；代價是要多裝一層、指令較多。純文書、公務用途通常用上面的原生五步驟就夠。

📌 帶走一句話

裝 Claude Code 其實就三塊：VS Code（家）＋ Node.js（引擎）＋ Claude Code（主角）＋ 一個付費帳號登入。裝好後從 Manual 模式開始，讓它每個動作都先問過你，你會用得又安心又順手。裝不了也別急——Claude Desktop 或網頁版一樣能用，只是不會「動手改檔」。
