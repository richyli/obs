digital narrative teaching 25

從 digital narrative index中挑出 25 個學生可用 vibe coding（AI 輔助寫程式）+ AI Agent 挑戰製作的代表作。每件作品的分析包含三層：

  1. 作品本身：原作做了什麼、好在哪、限制在哪
  2. 2026 重做路徑：以 Claude Code、Cursor、v0、Bolt 等 AI Agent 為主力，學生如何在 1-3 週內做出最小可行版
  3. 為何數位敘事優於文字/影像：這個方法在敘事上不可被替代的關鍵特性

篩選與排除

選：HTML/JS 靜態頁、D3 / Chart.js、Leaflet / Mapbox、Twine / 純 JS 遊戲、Streamlit / Gradio、Google Form / Sheet、OpenAI / Claude API、爬蟲

不選：3D 重建、VR / AR、感測器硬體、衛星影像分析、紀錄片影音、360 影片

2026 vibe coding 工具棧（通用建議）

關鍵心法：把 AI Agent 當成「會打字的實習生」——你給它清楚的目標、資料源、驗收標準，它幫你寫一版；你檢查、提需求、再迭代。學生作業的 80% 程式碼可以由 Agent 生成，學生的工作是設計問題、驗收結果、解釋為什麼這樣做。

25 件作品逐件拆解

01 The Climate Game（FT, 2022, 92）

  • 方法：分支劇本 + 條件分數 + 結局回顧
  • 2026 vibe path：① 用 Claude / GPT 寫氣候政策 trade-off 知識文件 → ② 把劇本結構化為 YAML（每個決策點有條件、影響、文字）→ ③ 用 v0 / Bolt 生成 React 遊戲頁，State 管理用 Zustand → ④ 部署 Vercel
  • 為何優於文字/影像：氣候 trade-off 是一個多變數、多時間尺度的決策樹，文字只能描述「如果 A 則 B」一條線，影片無法讓觀眾承擔決策後果。遊戲讓讀者體會 trade-off 的逼迫感——這是論述無法替代的認知。

02 Why Budapest, Warsaw, and Lithuania split（Pudding, 2019, 88）

  • 方法：滾動觸發地圖區塊變色 + 文字註解
  • 2026 vibe path：① 從 GADM / OSM 下載歐盟 NUTS 邊界 → ② 用 Claude Code 寫 d3-geo + Scrollama 元件 → ③ 用 Cursor 互動式調整 trigger 點 → ④ 部署 Cloudflare Pages
  • 為何優於文字/影像：行政劃分的視覺敘事核心是「同一塊地，被不同方式切割」——讀者需要在同一個地圖上看到不同方案的疊加。文字無法呈現這種空間覆蓋；影片則無法讓讀者掌握切換節奏。

03 The Structure of Stand-up Comedy（Pudding, 2018, 85）

  • 方法：時間軸視覺化 + tooltip
  • 2026 vibe path：① 用 yt-dlp + Whisper API 把脫口秀逐字稿轉文字 → ② 用 Claude 分類段落（鋪陳/笑點/收尾）→ ③ 用 v0 + D3 horizontal timeline 元件 → ④ 加上 hover 字幕
  • 為何優於文字/影像：脫口秀的節奏與密度是文字（段落感太弱）與影片（時間流逝太線性）都難以承載的。把整場 60 分鐘壓縮為一條可瀏覽的時間軸，讓讀者一眼看到笑點分布——這是視覺化獨有的「鳥瞰」能力。

04 Bussed out（Guardian, 2017, 92）

  • 方法：城市對城市流線地圖 + 個案故事 scroll
  • 2026 vibe path：① 用 Claude 找替代資料（如台灣移工出入境）→ ② 用 Mapbox + 自製 GeoJSON 流線 → ③ 用 Cursor 寫 Scrollama 章節切換 → ④ 整合個案訪談
  • 為何優於文字/影像：「政府用巴士把遊民送出州」的政策只能用流線地圖呈現——文字只能講「從 A 到 B」一個個案，影片無法同時呈現上千條流線。地圖把結構性現象一次推到讀者面前。

05 ToxMap（ProPublica, 2021, 92）

  • 方法：互動地圖 + 公開資料 + 個人化查詢
  • 2026 vibe path：① 從 EPA / 台灣 EPA 公開資料 API 抓 TRI 排放清冊 → ② 用 Claude Code 把 CSV 轉 GeoJSON → ③ 用 Mapbox GL + Cursor 寫互動圖層 → ④ 加上輸入郵遞區號的查詢框
  • 為何優於文字/影像：環境風險是地理性的——「我家附近多危險？」這個問題，文字只能給統計平均，影片只能給代表案例。地圖讓每個讀者看到屬於自己的答案。

06 The Force Report（NJ.com, 2018, 88）

  • 方法：靜態資料庫網站（搜尋 + 個案頁 + 警局聚合）
  • 2026 vibe path：① 用 OCR + Claude 整理 PDF 警方報告 → ② 用 Cursor + Astro / 11ty 從 JSON 生成 1000 個靜態頁 → ③ 加上 Algolia 搜尋
  • 為何優於文字/影像：5 年 7 萬筆武力使用記錄，任何文字摘要都會犧牲個案細節，影片無法快速跳轉。資料庫讓讀者「從統計鳥瞰 → 鎖定特定警員 → 看其全部紀錄」這條探索路徑，是新聞調查的核心。

07 Trial and Terror（Intercept, 2017, 86）

  • 方法：可篩選資料庫 + 個案詳情頁
  • 2026 vibe path：① 用 Airtable / NocoDB 管理資料 → ② 用 Softr 或 Cursor + React 生成前端 → ③ Claude Agent 自動爬取新案例補充
  • 為何優於文字/影像：恐怖主義訴訟分散在各州各年，新聞報導只能挑一兩件代表，但代表性正是爭點。資料庫讓讀者自己篩選比對——「不分種族篩出來呢？」「2010 年後呢？」——這是文字敘事不允許的多重視角。

08 Funes（Ojo Público, 2018, 88）

  • 方法：演算法評分 + 分數說明介面
  • 2026 vibe path：① 從政府電子採購網爬資料 → ② 用 Claude 設計評分規則（廠商集中度、價差異常、員工數比）→ ③ Streamlit / Gradio 顯示分數 + 為什麼
  • 為何優於文字/影像：「可疑標案」是統計 outlier，需要對全體比對才有意義。文字只能講個案；影片無法推算分數。演算法介面把判斷依據透明化——讀者看到分數同時看到指標，是新聞透明性的進化。

09 Dollars to Megabits（The Markup, 2022, 90）

  • 方法：爬蟲 + 個人化郵遞區號查詢
  • 2026 vibe path：① 用 Browser-Use Agent 自動爬電信商定價頁（每個 zip code）→ ② Claude 標準化資料 → ③ Cursor 寫查詢頁面（輸入 zip → 列出選項）→ ④ Vercel 部署
  • 為何優於文字/影像：「你被歧視性定價」這個論點只有當讀者親自輸入自家郵遞區號看到差距才有衝擊。文字平均值無法 personalize、影片無法互動。個人化是這類稽核新聞的本質。

10 What Does Opportunity Look Like Where You Live?（NYT, 2020, 88）

  • 方法：地址解析 + 條件比較圖
  • 2026 vibe path：① 抓內政部戶籍區資料 → ② 用 Google Geocoding API 把地址轉村里 → ③ Cursor 寫對照圖（你家 vs 全國）→ ④ 隱私聲明 + 不存儲
  • 為何優於文字/影像：「不平等」是抽象統計概念，文字（基尼係數）和影片（特寫個案）都無法讓讀者感受到自己在分布裡的位置。輸入地址看到「你家附近的扶養比 vs 全國」，把宏觀資料變成「我的故事」。

11 2020 大選社群廣告戰（READr, 2020, 80）

  • 方法：FB Ad Library + 候選人比對 microsite
  • 2026 vibe path：① 用 Meta Ad Library API 抓廣告投放 → ② Claude 標註廣告主題與情緒 → ③ Chart.js + Cursor 做時間 / 金額 / 觸及人數對比 → ④ 加上原始廣告截圖預覽
  • 為何優於文字/影像：選戰廣告投放是多維度動態資料（時間、金額、地區、觸及）。文字只能列重點數字，影片更不可能呈現對比。Microsite 讓對比的視覺結構承載分析。

12 給你珊時萬，你想投給誰？（關鍵評論網, 2022, 70）

  • 方法：情境多選 + 政黨向量推薦
  • 2026 vibe path：① 用 Claude 整理候選人政見差異 → ② 設計 10 題情境 + 政黨權重表 → ③ v0 直接生成測驗 UI → ④ Vercel 部署
  • 為何優於文字/影像：「你支持哪個黨」是個人化問題。文字政見比較是中立陳述；影片是候選人單向廣告。遊戲化讓讀者透過自己的選擇被告知自己的位置——這是說服力與自我認識的結合。

13 餐桌上的碳排（願景工程, 2022, 74）

  • 方法：表單輸入 + 公式計算 + 替代方案
  • 2026 vibe path：① 用 Claude 找 IPCC / 台灣 EPA 食物碳排係數 → ② Streamlit 表單（食材 + 量 + 餐次）→ ③ 用 GPT-4 即時生成「你今天的替代菜單」→ ④ Hugging Face Space 免費部署
  • 為何優於文字/影像：碳排是個人行為的量化結果。文字寫「肉類碳排高」是抽象訊息；影片無法讓觀眾算自己的。互動計算機讓讀者用自己的真實生活產生數字，是行為改變的入口。

14 從毒打到虐殺（窩窩, 2023, 80）

  • 方法：六篇報導 + Google Form 互動拼圖
  • 2026 vibe path：① 全部用 Google Form / Sheet（零程式）→ ② Sheet 寫公式自動評分 → ③ 嵌入網站作為延伸閱讀
  • 為何優於文字/影像：拼圖遊戲讓讀者主動參與動物虐待案件的法律判定過程，比起單向閱讀「定罪率低」這個結論，參與本身產生情緒投入。Google Form 路徑也示範沒有工程資源的小媒體仍可做互動。

15 ChatGPT 查詢兩千大（天下, 2023, 80）

  • 方法：自然語言介面 + 企業資料庫
  • 2026 vibe path：① 把 2000 大資料整理成 SQLite → ② 用 Claude Tool Use / OpenAI Function Calling 把 SQL query 包成 tool → ③ Cursor 寫 chat UI → ④ 加上引用顯示來源 row
  • 為何優於文字/影像：資料庫的完整探索成本太高——讀者不會一筆筆查。文字摘要犧牲個案；影片無法問問題。對話式介面讓讀者「問什麼就答什麼」，把資料庫從查詢工具變成新聞顧問。

16 Hot Disinfo from Russia（Texty, 2022, 85）

  • 方法：即時假訊息追蹤儀表板
  • 2026 vibe path：① 用 Claude Web Search + Telegram API 抓親克里姆林宮頻道 → ② Claude batch 標主題 → ③ Streamlit + 每小時 GitHub Actions 自動更新
  • 為何優於文字/影像：假訊息是即時演化的——昨天的話題今天可能變、新詞每週出現。文字報導必然落後；影片無法持續追蹤。儀表板讓讀者看到正在發生的資訊戰。

17 A River Drained: Mekong（Kontinentalist, 2022, 88）

  • 方法：跨國河川滾動地圖
  • 2026 vibe path：① 從 MRC（湄公河委員會）公開資料 + 衛星影像 API 抓水位 → ② Claude Code 寫 Mapbox 圖層切換 → ③ Scrollama 章節 → ④ 加上「你的食物有多少來自這條河」個人化結尾
  • 為何優於文字/影像：跨國河川議題的地理連動性（上游壩 → 中游漁 → 下游稻），用文字寫成「衝擊」太抽象、影片只能呈現某一段。地圖把因果鏈視覺化為空間。

18 Mass Killing Database（USA Today, 2022, 84）

  • 方法：搜尋資料庫 + 案件時序
  • 2026 vibe path：① 用 Claude 從 GVA / FBI 公開資料抓案件 → ② Astro 生成靜態頁（每案一頁）→ ③ 加上時序軸與類型篩選
  • 為何優於文字/影像：每年新增的暴力案件用文字報導會疲勞，影片無法一次承載 100 件。長期累積的資料庫讓「今年和過去比」「同類案件比」變成讀者的工具，而非新聞工作者的特權。

19 都市與氣候危機 海面上升（日經, 2022, 84）

  • 方法：滾動模擬全球機場淹水
  • 2026 vibe path：① 用 NASA SRTM 海拔資料 + 機場座標 → ② Mapbox + Cursor 寫海面高度 slider → ③ Scrollama 章節介紹城市 → ④ 加上你住的城市搜尋
  • 為何優於文字/影像：海平面上升是長期累進的——「2050 年上升 1m」這類陳述對讀者沒有時間感。互動讓讀者手動把海面拉高，看到熟悉的機場逐步消失，這種親手見證比影片重播更有衝擊。

20 Permian Basin 僵屍油井（Grist, 2023, 82）

  • 方法：環境 + 財務資料 + 地圖
  • 2026 vibe path：① 從 Texas Railroad Commission API 抓油井狀態 → ② Claude 計算復原成本 vs 政府預算 → ③ Mapbox 顯示廢棄井 + 點擊看財務 → ④ 對比加州、台灣海上石油平台
  • 為何優於文字/影像：「僵屍油井」議題需要同時看見地理分布 + 財務責任——這是兩維度資料。文字只能依序講、影片只能展示樣本。地圖 + 點擊財務面板讓讀者一眼看到「誰留下爛攤子」的空間政治。

21 Bahn Guru（2020, 78）

  • 方法：票價熱力地圖
  • 2026 vibe path：① 用 Browser-Use Agent 抓台鐵 / THSR 票價 → ② 計算每站從台北的最低票價 → ③ Cursor 寫地圖配色 → ④ 公開 Repo 讓社群維護
  • 為何優於文字/影像：交通票價是多對多比較——「從這裡出發，每個目的地最便宜票價是多少」。文字無法承載；影片無法即查。熱力地圖把比較直接視覺化為顏色。

22 追蹤全臺區段徵收案（READr, 2022, 81）

  • 方法：徵收案地圖 + 空屋率資料 join
  • 2026 vibe path：① 從內政部地政司抓徵收案 + 空屋率公開資料 → ② Claude 做地理 join → ③ Mapbox + Cursor 寫顏色梯度 → ④ 加上「你家附近有徵收案嗎」搜尋
  • 為何優於文字/影像：徵收案數量多（百件）、地理分散、與其他資料（空屋率）關聯。文字無法呈現分布、影片無法 join 兩份資料。地圖 + 篩選讓抽象政策爭議落地。

23 六都選民議員提案查詢（中央社, 2022, 80）

  • 方法：靜態資料庫 + 議員個案頁
  • 2026 vibe path：① 用 Claude 爬議會議事錄 → ② Astro 生成議員頁 → ③ 加上「你選區的議員提了什麼」查詢
  • 為何優於文字/影像：議員提案太多，新聞報導只能挑爭議件，但選民關心的是「我選的人做了什麼」。個人選區查詢才是公民工具的本質。

24 動物政見比一比（窩窩, 2022, 74）

  • 方法：政見比較表 + 立場標註
  • 2026 vibe path：① 用 Claude 從候選人 FB / 政見書抓動物政見 → ② Claude 標註立場（支持/反對/迴避）→ ③ 純 HTML 表格 + tooltip → ④ Cloudflare Pages
  • 為何優於文字/影像：候選人對單一議題的立場差異需要橫向比較。文字只能依序敘述各候選人；影片無法快速比對。比較表是民主辯論的基本格式。

25 2022 即時開票（READr, 2022, 79）

  • 方法：即時資料儀表板
  • 2026 vibe path：① 訂閱中選會即時 API（或定時 polling）→ ② Firebase Realtime Database 或 SSE → ③ Cursor 寫地圖 + 表格 → ④ 加 sound effect、動畫切換
  • 為何優於文字/影像：開票是即時、地理性、多重事件並行——電視只能切換幾個畫面，文字無法同步更新。儀表板讓讀者自己決定看哪一場，把媒體決定權交還給觀眾。

「為什麼數位敘事」的五大命題

從 25 件作品歸納出的核心邏輯——數位敘事在以下情境結構性地優於文字與影像：

命題 文字/影像的限制 數位敘事的解法 代表作
個人化：每個讀者看到屬於自己的答案 平均值、代表案例 輸入地址、選擇情境後動態生成 05、09、10、22
多維度比較：N 對 N 的橫向對照 線性敘事一次只能講一條 表格、地圖、圖表的並列 06、07、18、24
空間因果：地理是論證的一部分 描述「從 A 到 B」 地圖 + 流線、邊界、疊加 04、05、17、22
時間鳥瞰：把長時段壓縮為一覽 影片必須順序播放 時間軸、滾動軸、長期資料庫 03、18、19、25
決策體驗：讓讀者承擔選擇後果 文字只能假設、影片是被動觀看 遊戲、計算機、模擬器 01、12、13、19

判準：當你的故事有以上特性其中一個，數位敘事就比文字/影像更適合。三個以上時，數位敘事是唯一可行的形式。
