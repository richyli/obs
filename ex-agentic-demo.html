觀摩：Agentic Demo — 會動手的 AI（免安裝）

跨課程可重用。老師 demo 為主、學員看（非動手練習，format: class + demo_led: true）。用 claude.ai 網頁版 Connector 示範「會動手的 AI」，學員零安裝。適合放在對話式技巧都教完之後，讓學員看見上限。

🎯 目標

讓學員看見「對話式 AI」與「會動手的 agentic AI」的差別，並意識到自己哪件重複工作最該升級。

對話式 vs 會動手的 AI

  • 對話式（前面都在用的）：回你一段文字，動作你自己來（複製、貼上、對回 Word）。
  • Agentic（會動手的）：直接讀你的檔、改你的檔、串你的行事曆/雲端硬碟——你看它做、必要時喊停。

⏱️ 流程（55 分鐘）

1.（10′）講對話式 vs agentic 的差別（一張對照表）。 2.（30′）老師 demo 三段（見材料）。 3.（10′）講「為什麼它能懂你單位」（三層記憶：格式/偏好/一鍵指令）。 4.（5′）收束：什麼時候該升級。

📋 材料（老師 demo，免安裝路線）

三段 demo（claude.ai 網頁點一次 Connector 即有）：

  1. 行事曆祕書（Google Calendar Connector）：「看我下週哪天最空，幫某個會找一小時空檔並建立」→ 它回表、你確認、它建好。示範「描述意圖，它選工具執行」。
  2. 雲端硬碟彙整（Google Drive Connector）：「讀我這個資料夾裡幾份回覆，彙整成一張總表」→ 對照手動一份份上傳，看差在哪。
  3. 法規 redline 放大（回扣「法規比對」練習）：老師端用真 Claude Code demo「兩檔並排 diff＋逐條對照」，看對話式做不到的那塊。

三層記憶（點到不深講）：會動手的 AI 之所以像「跟你三年的資深承辦」，是因為它記得你的格式（單位守則）、偏好（主管不喜歡的用語）、把常做的事做成一鍵指令。

✅ 收束訊息

當你發現「同一件事，我每週都在重貼背景、重上傳檔」——那就是該從對話式升級到會動手的 AI 的訊號。

🆘 老師端注意

  • 課前先在 claude.ai 串好 Google Calendar 與 Drive Connector、確認現場網路不擋。
  • 真 Claude Code 的 diff demo：備好兩版法規檔、示範資料夾 Open Folder。
  • 機關/校園網路常擋 claude.ai 與 Firebase，務必事前用現場網路測。

🔀 變體

  • 大學課版：demo 三段換成「行事曆排期末報告」「Drive 彙整分組作業」「兩版論文 diff」。
  • 純觀摩不 demo：網路受限時改放預錄影片。
