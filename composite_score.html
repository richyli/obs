composite_score

composite_score 是 PLS-SEM 對潛在構念的具體實作：以觀察變項加權組合算出的數值，每個受試者都有一個。

Mode A（reflective）：權重由 PLS 演算法迭代決定。 Mode B（formative）：權重以多元迴歸從指標到構念決定。

對比 CB-SEM 的因子分數：CB-SEM 因子是統計推導的潛變項；composite 是確定性線性組合。

方法說明

目的

  • 在 PLS-SEM 中以指標的加權組合代表潛在構念，每位受試者得到一個構念分數
  • 區分 reflective（Mode A）與 formative（Mode B）兩種測量模式
  • 提供確定性的線性組合替代 CB-SEM 的因子分數估計

流程

  1. 設定測量模式（Mode A 或 B）
  2. PLS 演算法迭代估計權重
  3. Mode A：權重由內部估計（迴歸）決定
  4. Mode B：權重以多元迴歸從指標到構念決定
  5. 計算 composite：$\xi = \sum w_i x_i$
  6. 評估
  7. Mode A：indicator reliability、composite reliability、AVE
  8. Mode B：weights significance、collinearity（VIF）
  9. 結構模型階段使用 composite 進行路徑估計

適用範圍

  • 適用：PLS-SEM、預測導向研究、formative 構念、小樣本（$n \geq 100$）
  • 不適用：純驗證性 confirmatory 假設檢定（改用 CB-SEM）
  • 樣本規模建議：依 10-times rule 或 minimum-$R^2$ 法則（暫無 wiki/ 資料）
  • 資料類型要求：多指標反映或構成的構念
