Plug-in

Claude-Mem

https://hackmd.io/@BASHCAT/S1tqslOwWe?utm_source=preview-mode&utm_medium=rec https://github.com/thedotmack/claude-mem

最近出的Claude-Mem算是解決了Claude Code長期以來的一個明顯短板。

很多人在使用 Claude Code 時都會遇到同樣的問題：沒有跨對話的持久記憶。每次重開 session，都必須重新說明專案背景、架構與需求，不只消耗 token，也打斷工作節奏。

這個專案做的事情很單純但很關鍵，把過去對話與操作內容自動整理、壓縮，再在未來對話中只注入「真正相關的上下文」，而不是全部塞回去。

它的做法包含幾個核心機制：

• 自動捕捉使用過程中的內容

• 透過 AI 進行記憶壓縮

• 只在需要時載入關鍵上下文

• 分層式提取資訊，而不是一次讀取所有資料

官方提到，這樣可以顯著降低每次對話所需的 token 數量，最多可將每次對話所需的 token 減少 95%，同時讓工具呼叫次數變得更有效率。

安裝方式也很簡單，兩個指令就能啟用，重啟之後就能開始使用持久記憶。

目前 GitHub 星數已飆升29.9k，如果你長期在用 Claude Code 開發專案，這類「記憶層」工具很值得關注。它不只是省 token，而是試圖為 AI 工作流建立一層更穩定的長期上下文管理機制。

Interface

  • Plan Mode

  • pwd — "Where am I right now?"

  • ls (Mac) or dir (Windows) — "What's in this folder?"

  • cd foldername — "Go into this folder"

  • cd .. — "Go back up one level"

  • mkdir projectname - "Make a new folder"
pwd                    # Computer says: /Users/yourname
ls                     # Computer shows: Documents, Downloads, Desktop
cd Documents           # You go into Documents folder
mkdir my-first-project # You create a new folder
cd my-first-project    # You go into that new folder

一行指令，秒開「Yes-All」模式

最簡單暴力的做法，就是在任何 claude 指令後面加上：

claude --yes --skip-confirm

  • --yes：對所有「y/n」問題自動回答 yes
  • --skip-confirm：跳過任何需要人類二次確認的步驟

把這行寫進你的 Makefile 或 package.json script，之後只要 npm run claude 就能全自動跑。

永久設定：讓 .claude.json 幫你記住

不想每次打參數？在專案根目錄放一個 .claude.json，貼上：

{ "autoYes": true, "skipConfirm": true, "silent": false }

存檔後，無論誰跑 claude 都會自動 yes。
（小提醒：把 .claude.json 加進 .gitignore，避免隊友被強迫自動化。）

環境變數也行：CI/CD 最愛

GitHub Actions、GitLab CI 或任何容器環境，只要在 env 區塊加：

CLAUDE_AUTO_YES: 1 CLAUDE_SKIP_CONFIRM: 1

這樣就算在無互動的容器裡，Claude Code 也能乖乖閉嘴執行。

常見坑位速查表

情境 指令範例 備註
本地測試 claude --yes --skip-confirm 先跑一次看看會不會刪錯檔
CI 環境 claude --yes --skip-confirm --silent --silent 可關閉進度條，減少 log 噪音
多人協作 .claude.json 加 .gitignore 避免隊友被迫自動 yes
安全顧慮 加 --dry-run 先預覽 確認沒問題再去掉 --dry-run

進階：只在特定步驟自動 yes

有時你想讓 Claude Code 自動重構，但部署前還是想親眼看一眼。這時可用「分階段指令」：

# 自動重構 claude refactor --yes --skip-confirm # 部署前再問我 claude deploy

結語：把「提問」留給人類，把「執行」交給 Claude Code

設定好 --yes 與 .claude.json 後，你就能把重複性工作完全託管給 Claude Code。記得先在測試專案跑一次，確認它不會把整個 repo 刪光，再正式上線。自動化不是偷懶，而是把大腦留給更有創意的事。
