儀表板九組對照

九條理論，每一條配一組並排的真實例子。例子全部來自同一份作業——五位學生用同一份 2016 立委政治獻金資料（261 位候選人）各做一個互動儀表板。同樣的資料、同樣的時間，做出來的東西在這九個地方分岔了，而每一個分岔背後都有一條可以查的理論。

對照組　9 組 來源　5 件學生作品 資料　2016 立委政治獻金 · 261 人 證據　各作品原始碼實測

理論怎麼挑的

不是先列理論再找例子，是反過來——先看這五件作品在哪些地方真的分岔了，再回頭找那個分岔對應哪一條理論。一條理論如果五件作品做得一樣好或一樣差，就沒有選進來，因為它教不出東西。

每一組的證據都是從作品原始碼實測出來的：色碼數量、CSS 選擇器、按鈕的 padding、下拉選單的選項數、載入的函式庫。這些都可以自己開瀏覽器檢視原始碼複驗。

下面每一格的小圖是依作品實際數值與色碼重製的示意，不是螢幕截圖——為了讓兩邊在同一個尺度下並排比較。要看真正的樣子，開作品本身。

01

顏色的數量上限

Subitizing 的上限大約 4–5 個：在這個數量以內，人可以「一眼數完」不必逐一掃描。顏色一旦超過這個數量，辨色就從前注意的平行處理掉回序列搜尋，圖例必須一個一個讀。Subitizing · Feature Integration Theory

好W4 THE CAPITAL 2016
全站 6 個色值

整個站只有黑、白與四階灰。顏色完全不承擔語意，層次全部交給字級、粗細與線寬。要判斷哪裡重要，看的是排版，不是顏色。

CSS 變數只有四個：
--black #000000
--white #FFFFFF
--border-thick 2px solid #000
--border-thin 1px solid #000

不好W2 政治獻金大公開
單一頁面裡的 26 個色值

CSS 裡其實有一套很有紀律的語意色盤，但 HTML 裡又另外散落了 26 個色碼，等於兩套色彩系統並存。使用者無法從顏色推論任何規則，只能回頭讀圖例。

style.css 定義 14 個語意變數；
index.html 內另有 26 個 hex，
其中光紅色就四個：
#f44336 #e53935 #ff1744 #c0392b

怎麼改先決定顏色要不要承擔語意。要，就把色票鎖進 CSS 變數，全站只准從那裡取色；不要，就學 W4 交給排版，反而更難出錯。

02

信號的特徵必須專屬

顏色、動態、大小這些前注意特徵在 200–250 毫秒內被平行偵測，不需要注意力。但同一個特徵若被多種意思共用，它的信號純度就消失了——紅色同時代表「警示」和「某個分類」的時候，紅色什麼都不代表。Feature Integration Theory · Pre-Attentive Processing

好W2 的政黨色
四個政黨 · 四個固定色

四個政黨各綁一個色碼，寫成 CSS 變數，全站不變。這是相似性原則的正確用法：同一個視覺特徵永遠對應同一個意思，使用者看兩頁就學會了。

--dpp #1B9931　--kmt #1565C0
--npp #B8860B　--ppp #FF6B35

不好W2 的紅色
同一份作品裡的五個紅

同一件作品，色彩紀律在 CSS 裡有、在 HTML 裡沒有。五個紅分散在強調、分類、標記各處，等到真的需要一個「這裡要立刻處理」的紅，已經沒有紅可以用了。

--crimson #8B0000 是語意紅；
另外四個紅寫死在 HTML 內，
用於分類標記與強調。

怎麼改挑一個顏色當警示專用色，然後全站搜尋一次，把其他地方用到它的都換掉。這件事十分鐘就做得完，但只有想過「信號專屬」的人才會去做。

03

裝飾會製造假信號

任何不代表資料的視覺變異，都會在顯著性地圖上產生無意義的激活。陰影與漸層製造出強烈邊緣，大腦得額外花力氣忽略它們，才看得到真正的資料。Data-Ink Ratio · Feature Congestion

好W4 THE CAPITAL 2016
TOTAL INCOME
NT$ 12,480,000
CORPORATE 41%
2px 實線 · 0 漸層 · 0 陰影

邊界只用純黑細線，沒有圓角、沒有陰影、沒有漸層。整頁唯一的視覺變異就是資料本身，數字要突出時靠字級，不靠特效。

gradient: 0 處
box-shadow: 0 處
border: 2px / 1px solid #000

不好W5 2016 金權政治獻金資料庫
總收入
NT$ 12,480,000
企業捐贈 41%

視覺語言本身很完整，金色與酒紅的搭配也撐得起「金權」這個題目。但變異全部集中在裝飾上——每一張卡片都在發光，於是沒有一張卡片是重點。

golden_politics2016.css：

box-shadow 7 處 · 36 個色值

怎麼改不是把裝飾全砍掉，是讓裝飾只出現在不承載資料的地方。標題區可以華麗，數字區要素。先做一次減法，再決定要加回哪一項。

04

同一份資料，兩種編碼

視覺通道的判讀準確度有明確排序：共同尺度上的位置最準，其次是長度，再來才是角度、面積、亮度。最重要的比較應該用最有效的通道。Perceptual Ladder · Cleveland & McGill

六個捐贈來源畫成共用左端基線的長條，用寬度百分比呈現。要回答「個人捐贈是不是比營利事業多、多多少」，眼睛可以直接比長度，不必換算。

05

入口要有好幾條

人像覓食動物一樣，靠「資訊氣味」決定要不要往下深入。不同任務需要不同的覓食路徑：查特定的人、依分類瀏覽、開放探索、回頭找看過的——只給一條路，就是只服務其中一種人。Information Foraging Theory

好W5 2016 金權政治獻金資料庫
簡易搜尋　候選人／政黨／選區 進階搜尋　政黨 × 委員會 × 地區 範例查詢　直接給三組現成條件 編輯精選　柯建銘／王定宇／黃國昌 企業捐贈排行
五種進入方式

五條路各自服務一種人：知道要查誰的、只想篩條件的、不知道從哪開始的、想看熱門的、想看整體結構的。頁內導覽把這五條路直接列在最上面。

不好W4 THE CAPITAL 2016

實際上只有一條路

入口只有地圖，加三個城市的快捷鍵。想找特定候選人、想比較政黨、想看企業捐贈排行的人，全部沒有路可以走——地圖很漂亮，但它預設了每個人都從地理位置開始想事情。

select 0 個 · input 1 個 · button 5 個

06

但選項不能一次全給

決策時間隨選項數的對數成長。這條和上一條是一體兩面：入口要多條，但每一條入口上的選項要少——多入口不等於多選項。Hick-Hyman Law

07

先給杯腳，再給杯碗

Martini Glass 結構：先由作者引導一段，把詮釋框架建立起來，再打開讓讀者自由探索。沒有杯腳，讀者是在沒有框架的情況下面對一個資料庫。Narrative Visualization

08

第一個畫面就要是完成的

空間包絡在約 100 毫秒內被辨識，激活「這是什麼類型的畫面」的先驗。第一個畫面如果是空的，這 100 毫秒就浪費掉了，使用者得等第二次機會。Scene Grammar Theory

09

點得到才算做得到

移動到目標的時間，隨距離增加、隨目標縮小而變長。操作成本高，等效於提高行動門檻——按鈕做得太小，功能等於沒做。Fitts's Law
