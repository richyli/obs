parametric_MGA

parametric_MGA 是 PLS_MGA 的 t-test 法（Keil et al., 2000）。

公式：$t = (\beta_1 - \beta_2) / \sqrt{SE_1^2 + SE_2^2}$

假設兩組變異相等。若不等，改用 Welch_Satterthwaite。

vs Henseler_PLS_MGA：parametric 較傳統，現代 PLS 多偏好 Henseler_PLS_MGA 的 permutation 法。

方法說明

目的

  • 主要研究目的：以參數化 t-test 比較 PLS-SEM 路徑係數在兩群之間是否顯著不同
  • 次要用途：作為 permutation 法的對照與診斷

流程

  1. 對兩群分別跑 PLS-SEM，取得 $\beta_1$、$\beta_2$ 與其 bootstrap 標準誤
  2. 以 $t = (\beta_1 - \beta_2) / \sqrt{SE_1^2 + SE_2^2}$ 計算統計量
  3. 用 $df = n_1 + n_2 - 2$ 對應 t 分配查 p-value
  4. 若兩群變異不等，改用 Welch_Satterthwaite 修正自由度
  5. 報告路徑差異與 95% CI

適用範圍

  • 適用：兩群比較、樣本量相近、變異近似的情境
  • 不適用：變異嚴重不等或樣本極不平衡（改用 Henseler permutation 或 Welch）
  • 樣本規模建議：每群 N ≥ 100
  • 資料類型要求：通過 MICOM 至少 metric invariance 的兩群
