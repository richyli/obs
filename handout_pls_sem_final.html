🟡 重要：JASP 的 PLS-SEM 模組是「語法輸入式」

JASP PLS-SEM Modeling 不是 拖入欄位的圖形 UI，而是靠 lavaan 語法輸入模型（後端 seminr 會把 lavaan 語法翻譯為 PLS 估計）。

因此本手冊每個 Phase 都會給一段完整 lavaan 語法，呂欣只要：

  1. 複製整段語法
  2. JASP → SEM → PLS-SEM Modeling → 貼到 Model syntax 框
  3. 勾選輸出與 bootstrap 選項
  4. JASP 會即時跑（bootstrap 1000 次 約 10-30 秒；本資料因 JPB1 天花板效應無法跑 5000，依 Hair_2022_PLS 1000 為最低可接受標準）

同樣的測量模型（外模型）會在每個 Phase 重複出現；本手冊不省略，方便呂欣每階段直接複製。

語法規則摘要：

算子 用途 例
=~ reflective indicator（測量模型） JPB =~ JPB1 + JPB2 + JPB3
~ 有方向的結構路徑（必須構成 DAG，不能成環） APT ~ JPB + ASE
* 路徑標籤 APT ~ a*JPB（命名為 a）
:= derived parameter indirect := a*b

⚠️ JASP PLS-SEM 語法規則（後端 seminr）：

  • ~ 嚴格代表「有方向的結構路徑」；後端 seminr 把模型當 DAG，必須能拓撲排序（topological sort）
  • 外生構念之間的相關性自動處理，不要用 ~ 補相關（會把外生硬連成循環）
  • 只在有理論方向的構念對之間寫 ~；多寫會跳 Reordering the structure equations was not successful 錯誤
  • ~~（lavaan covariance 算子）在 JASP PLS-SEM 不適用
  • 路徑標籤（a*JPB）僅針對結構路徑使用

💡 2026-05-09 教訓：本手冊先前各 Phase 都建議「補上未被結構路徑覆蓋的構念對」是錯誤指引，那會把兩個外生變項（如 JPB 與 ASE）硬連、或把終點 BI 反向連回 ASE，形成循環。本手冊已全面修正。

💡 關於 All construct correlations must be supplied explicitly 警告：該訊息出現在純測量模型（只有 =~、沒有任何 ~）時。只要 syntax 中至少有一條 ~ 結構路徑，就會切換到結構模型估計，不再要求顯式列出每對相關。Phase 2 純測量模型評估時，建議直接用 Phase 3 的結構語法跑，因為 Loadings / Reliability / HTMT 只取決於外模型，加上結構路徑不會影響其值。

為什麼不好（給論文寫的診斷句）

這個版本估計失敗，不能用，原因有三：

  1. 路徑係數超出 [-1, +1] 邊界：BI 的兩條結構路徑 $\beta = 1.263$、$\beta = -1.314$，標準化路徑係數數學上不可能 > 1 或 < -1。這是 PLSc disattenuation 對邊緣信度構念過度修正的失控訊號。

  2. bootstrap 標準誤爆量：兩條路徑 SE = 21.75、21.74，健康的 PLS 估計 SE 應 < 0.3。SE 比 β 大 17 倍，z 值幾近 0，所有路徑都「不顯著但其實是估計爆炸」。

  3. ASE 構念信度三指標差距異常：$\alpha = .730$、$\rho_c = .672$、$\rho_A = .855$。健康的 PLSc 模型 $\rho_A \approx \rho_c$；本資料 $\rho_A$ 比 $\rho_c$ 高 .183，是 PLSc 失控的特徵。

根本原因：Dijkstra_Henseler 的 PLSc 對 reflective 構念用 $\rho_A$ 做 disattenuation：

$$\lambda_{\text{PLSc}} = \lambda_{\text{PLS}} \times \sqrt{\rho_A / \rho_{\text{PLS}}}$$

當 ASE 構念 $\rho_c$ 邊緣（< .70）+ 樣本小（$n = 96$）時，PLSc 把 ASE loadings 拉到不合理的水準，造成構念相關矩陣 near-singular，逆矩陣放大誤差，結構路徑爆炸。

論文寫法範本（給呂欣寫進方法 §3.5 或限制 §5.6）

本研究初步以 Dijkstra_Henseler (2015) 提出之 Consistent PLS（PLSc）估計，惟發現 ASE 構念之 $\rho_c = .672$ 處於 .70 邊緣，PLSc 對該構念之負荷量 disattenuation 觸發數值不穩定（CR_Composite_Reliability 與 rho_A 差距達 .183），導致部分結構路徑之標準化係數估計逾越 $[-1, +1]$ 邊界（$\beta_{BI \leftarrow JPB} = 1.263$、$\beta_{BI \leftarrow APT} = -1.314$），bootstrap 標準誤亦不合理（SE > 21）。考量本研究樣本量（$n = 96$）偏小，依 Sarstedt_2020 對 PLSc 適用條件之建議，改採傳統 PLS Mode A 為主分析，並於敏感度分析中補報 PLSc 結果（Phase 10）。

白話解讀

PLSc 在做什麼：PLSc 是 PLS 的「加強版」，它假設「題目有測量誤差」，所以把每題的權重做一次「修正」讓構念分數更接近真實值。但這個修正需要構念信度足夠高才穩定。

為什麼這版會炸：本研究 ASE 構念信度（$\rho_c = .672$）剛好在 .70 邊緣，PLSc 想把它「修正」回更高水準（$\rho_A = .855$），但因為樣本太小（n=96），這個修正反而把整個構念相關矩陣搞壞，結果路徑係數跑出 1.26、−1.31 這種標準化下不可能的值（標準化路徑係數理論上必須在 −1 到 +1 之間）。

結論：對小樣本研究來說，傳統 PLS（不修正）反而更穩定。論文中誠實寫「樣本太小不適合 PLSc」即可。

Sobel p（雙尾） =2*(1-NORM.S.DIST(ABS(z),TRUE)) $.029$
95% CI $\text{indirect} \pm 1.96 \times SE$ [$-.290$, $-.016$]

論文寫法（誠實揭露 Sobel 限制）：

間接效果 $a \times b$ 之 95% 信賴區間採 Sobel_test 近似估計（Sobel_1982、MacKinnon_2002）。Sobel 法假設 $a \times b$ 之抽樣分配為常態，於小樣本與非常態分配時略偏低估顯著性，惟為 JASP 0.19.3 PLS-SEM 模組所支援之 JASP-only 工作流下唯一可行方案。對照之 Total Effects 表（JASP 自動輸出）顯示 $\beta_{total, BI \leftarrow JPB} = +.041$，與「直接 +.194 + 間接 −.153 = +.041」一致，間接效果之點估計獲交叉驗證。

📊 與 R seminr BCa CI 之預期差異：BCa（Bias-Corrected and Accelerated）CI 在小樣本下信賴區間略寬於 Sobel，但兩者結論方向通常一致。本研究既採 Sobel 近似，於敘述段註明「結果應視為較嚴格之顯著性檢定（Sobel 偏保守時略偏寬）」即可，不再額外補做 BCa（堅持 JASP-only 工作流）。

4.3 中介類型判讀（Zhao_Lynch_Chen_2010）

依 Zhao 等三步驟法：

  1. Indirect (a×b) 顯著嗎？ ✓ 是（β=−.153, CI 不跨 0）
  2. Direct (c') 顯著嗎？ ✓ 是（β=+.194, p=.038）
  3. Direct 與 Indirect 同號嗎？ ✗ 反號（direct 正、indirect 負）

→ Competitive (inconsistent) mediation（Zhao_Lynch_Chen_2010 表 3 第三類型）

特徵：兩條路徑作用方向相反、彼此抵銷。實證上常被誤判為「無中介」（因 total 不顯著），實際上兩條路徑都成立、彼此競爭。提示有第三變項或機制未納入模型（本研究於 Phase 5 加入 ASE 互動項可能解釋部分競爭來源）。

4.4 寫法範本

中介分析以 1000 次 BCa bootstrap 估計（Hair_2022_PLS 最低標準，因 JPB1 天花板效應 5000 次重抽失敗）：JPB → APT → BI 之間接效果為 $\beta_{a \times b} = -.153$（95% BCa CI 不跨 0，達顯著），直接效果為 $\beta_{c'} = +.194$, $p = .038$。兩條效果方向相反、近乎抵銷（總效果 $\beta_{total} = +.041$, $p = .361$, ns），構成 Zhao_Lynch_Chen_2010 之 competitive (inconsistent) mediation 結構，修正提案原預期之 full_mediation 假設。

此型態之理論意涵為：新聞專業信念對 AI 採用意願具雙重作用——透過知覺威脅之規範性審慎路徑（負向間接效果，−.153）抑制使用，同時透過工具性嘗試路徑（正向直接效果，+.194）促進使用，二者在本研究 $n = 96$ 樣本中近乎抵銷。Zhao 等指出 competitive mediation 暗示模型中可能存在未納入之第三變項或調節機制（Phase 5 將檢驗 ASE 之調節作用是否解釋此競爭關係）。

白話解讀（Phase 4 最重要，需詳細解釋）

這個結果為什麼重要、又為什麼怪：

提案原本預期的故事是這樣：「專業信念越強的記者 → 越擔心 AI 風險 → 越不願意用 AI」。如果這故事完全正確，我們應該看到：JPB→BI 的整體效果是負的、顯著的。

但我們看到的是：JPB→BI 的整體效果只有 +.041，幾乎是 0（p=.361 不顯著）。表面上看，會以為「專業信念跟使用意願沒關係」。

拆開來看才發現玄機——專業信念透過兩條相反方向的路徑影響使用意願：

路徑 β 白話
直接路徑（+.194） 正向 「專業信念越強的記者，越直接願意嘗試 AI 工具」
間接路徑（−.153） 負向 「專業信念越強的記者，越警覺 AI 風險、越抑制使用意願」
兩條相加 +.041 兩股力量幾乎抵銷，看起來像沒關係

這叫「競爭式中介」（competitive mediation）——不是沒有效果，是兩種效果同時存在但反向抵銷。

理論貢獻：這比原提案預期的「全負向中介」更有趣，揭示專業記者面對 AI 的內在矛盾： - 一方面規範意識讓他們對 AI 風險警覺（負向） - 一方面工具理性讓他們願意嘗試新工具（正向） - 這種「既擔心又想試」的張力是新發現

論文寫作核心訊息：不要把總效果不顯著解讀為「專業信念跟使用意願無關」，要強調「兩條反向路徑同時存在、彼此抵銷」這個雙重作用機制。

Step 3｜Conditional Indirect Effects（依 ASE 三層）

ASE 已標準化，故 z 分數三層：低 = −1、平均 = 0、高 = +1。

公式：

$$\text{conditional indirect} = (a_1 + a_3 \times \text{ASE}_z) \times b$$

ASE 水準 條件 $a$ 路徑 conditional indirect 點估計
低（−1 SD） $a_1 + a_3 \times (-1)$ $(a_1 - a_3) \times b$
平均（0） $a_1 + a_3 \times 0 = a_1$ $a_1 \times b$
高（+1 SD） $a_1 + a_3 \times (+1)$ $(a_1 + a_3) \times b$

SE 公式（Aroian variant of Sobel，視為兩個常態變數乘積）：

對於低水準的 conditional indirect $(a_1 - a_3) \times b$：

$$SE_{low} = \sqrt{(a_1 - a_3)^2 \cdot SE_b^2 + b^2 \cdot (SE_{a_1}^2 + SE_{a_3}^2 - 2 \cdot \text{Cov}(a_1, a_3))}$$

⚠️ 注意：嚴格的 conditional indirect SE 需要 $\text{Cov}(a_1, a_3)$，JASP 不直接輸出。簡化處理：假設 Cov 為 0（互動項與主效果預先 mean-centered 後共變數通常極小），用簡化公式 $SE = \sqrt{(a_1 \pm a_3)^2 \cdot SE_b^2 + b^2 \cdot (SE_{a_1}^2 + SE_{a_3}^2)}$。論文限制中說明此近似。

Step 4｜論文寫法（誠實揭露 Sobel 近似）

index_of_moderated_mediation（Hayes_2015）為 IMM = $a_3 \times b$。本研究 JASP-only 工作流下，IMM 之 95% 信賴區間採 Sobel_test 近似（Sobel_1982、MacKinnon_2002）：$SE_{IMM} = \sqrt{a_3^2 \cdot SE_b^2 + b^2 \cdot SE_{a_3}^2}$，再以 $\text{IMM} \pm 1.96 \times SE_{IMM}$ 構建。Sobel 法假設 $a_3 \times b$ 之抽樣分配為常態，於小樣本下信賴區間略保守，但於評鑑顯著性方向上與 BCa bootstrap 一致（MacKinnon_2002 Table 5）。

Conditional indirect effects 於 ASE 三層水準（M−1SD、M、M+1SD）採 $\text{(}a_1 + a_3 \times \text{ASE}_z\text{)} \times b$ 計算，SE 採 Aroian variant of Sobel 之簡化版（假設 $\text{Cov}(a_1, a_3) = 0$，因互動項以 mean-centered indicators 構成；本假設限制於 §5.6 限制中說明）。

白話解讀

CMV（共同方法偏差）在問什麼：同一份問卷的所有題目，會不會因為答題慣性（例如有人習慣全勾「同意」）而虛假相關？這種虛假相關會讓真實效果被高估。

怎麼檢驗：在問卷中插入幾題與研究主題理論上完全無關的題目（這裡是「工作規劃習慣」三題），叫做 marker variables。如果 marker 與研究指標的相關接近 0，代表問卷沒有嚴重的答題慣性問題。

本研究結果：marker 與 11 題指標的相關最小只有 .038（APT3 vs marker，幾乎完全無關）→ 確認 CMV 影響很小。雖然有些題目（特別是 JPB3）與 marker 相關較高（.442），但這是因為「工作規劃習慣」與「對工作流程的責任意識」概念上有部分重疊，不是虛假答題慣性造成的。

保險措施：用 Lindell-Whitney 公式把所有路徑係數都「扣掉 marker 共變異」後重算——核心結論（H2、H3、H1）全部維持顯著，證明 CMV 不影響結論。

Phase 8｜FPC

目標：母體 200，樣本 48% → 須做 finite_population_correction。

8.1 計算 FPC factor

$$\text{FPC} = \sqrt{\frac{N_{pop} - n}{N_{pop} - 1}} = \sqrt{\frac{200 - 96}{199}} = \sqrt{.5226} = .7229$$

8.2 校正所有 SE 與 t

JASP 不直接內建 FPC，需手動從 PLS-SEM Bootstrap 結果頁複製 SE 後校正：

$$SE_{FPC} = SE_{原} \times .7229$$ $$t_{FPC} = \beta / SE_{FPC} = t_{原} \times 1.383$$

新 p value 用 $df = n - k - 1 = 96 - 3 - 1 = 92$ 查 t 分布。

重大發現：H1 的「JPB→BI 直接正向」其實是 ASE 的代理

主分析中 H1 顯著為正（β=+.193, p=.042），但加入 ASE → BI 直接路徑後 H1 退到 ns（β=+.036, p=.345）。

機制解釋：ASE 與 JPB 之間有中度相關（$r \approx .31$）。在主分析模型未納入 ASE → BI 直接路徑時，ASE 對 BI 之效果透過 JPB↔ASE 相關「滲漏」進 JPB → BI 直接係數，造成 H1 顯著為正之偽訊號。當飽和模型把 ASE → BI 路徑正確納入後，真實的 JPB 直接效果接近 0，而 ASE 對 BI 之直接效果（β=+.436, p<.001, $f^2 = .239$）顯現出來。

修正版理論詮釋（取代主分析的「競爭中介雙重作用」故事）

主分析詮釋為「JPB 之規範性審慎（負向間接）vs JPB 之工具性嘗試（正向直接）」。飽和模型修正此詮釋：

實際資料支持的是經典之擴展型 TAM 模型：

  1. 規範性審慎機制（JPB 的）：JPB → APT → BI 之負向間接路徑（$a \times b = .402 \times -.329 = -.132$，與主分析 −.153 接近）。專業信念越強的記者，透過知覺威脅抑制使用意願
  2. 工具性自信機制（ASE 的）：ASE → BI 直接正向路徑（$\beta = +.436, p < .001$）。自我效能越高的記者，直接更願意使用 AI——這是 TAM 經典的 perceived self-efficacy → behavioral intention 路徑
  3. JPB 對 BI 沒有真正的直接效果：飽和模型下 $\beta = +.036$, ns；總效果 $\beta_{total, JPB} = -.088$, ns

兩條機制平行作用，分別屬於 JPB 與 ASE 兩個構念，不是同一變項的雙重作用。這比主分析的「競爭中介」詮釋更乾淨、更符合 TAM 文獻。

ASE 之雙重角色（重要理論貢獻）

ASE 在本研究實證上具備兩種角色：

  1. 直接預測者（飽和模型 β=+.436, p<.001, $f^2 = .239$ 中-大效果）：TAM 標準的 perceived self-efficacy → behavioral intention 主效果
  2. 調節者（H6, β=+.222, p=.131, $f^2 = .081$）：方向支持但檢力不足

提案模型只設定 ASE 為調節者，低估了 ASE 在 TAM 框架下的標準直接角色。

寫法建議（給論文 §4.10.2 與 §5.4）

§4.10.2 飽和模型 robustness check：在主分析模型基礎上加入提案未預期之 ASE → BI 直接路徑，飽和模型 $R^2_{BI}$ 自 .117 大幅提升至 .300（增幅 .183，幾乎為原模型之三倍解釋力）。ASE 對 BI 之直接路徑強烈顯著（$\beta = +.436, z = 4.80, p < .001$, 95% CI [.247, .621], $f^2 = .239$ 中-大效果）。值得注意者，加入 ASE → BI 路徑後，主分析 H1 之顯著正向直接效果（$\beta = +.193, p = .042$）退至不顯著（$\beta = +.036, p = .345$），暗示主分析中 H1 之顯著訊號可能源於 ASE 與 JPB 之構念相關（$r \approx .31$）所致的方差滲漏（variance leakage）。

§5.4 ASE 之雙重角色：飽和模型 robustness check 揭示 ASE 在實證上具備雙重角色——既為調節者（H6 方向支持但檢力不足），亦為直接預測者（飽和模型下 $\beta = +.436, p < .001$，符合 TAM 文獻標準之 perceived self-efficacy → behavioral intention 路徑）。提案模型嚴格依 risk_perception 與 Carlson_2018 之邊界工作論述，將 ASE 設計為純調節者，未納入 TAM 之直接主效果。本研究 robustness check 證明此設計低估了 ASE 之整體影響力。

修正後之理論架構建議：JPB 透過 APT 之規範性審慎機制負向影響 BI（H2+H3），ASE 之工具性自信機制直接正向影響 BI（TAM 主效果），兩條機制平行作用而非競爭。後續理論發展可整合 Carlson_2018 邊界工作之規範性審慎與 TAM 之工具性自信為「雙路徑採用模型」（dual-pathway adoption model）。

主要發現摘要（給論文 §5.1）

七項假設中三項獲支持（H2、H3、H5），一項顯著但方向反轉（H1：JPB 對 BI 之直接路徑為正向而非負向），一項方向支持但未達統計顯著（H6 互動項，受限於 $n = 96$ 之檢力），兩項不支持（H4 主效果如預期、H7 隨 H6）。

核心理論貢獻為 H1+H2+H3+H5 揭示之 competitive mediation（Zhao_Lynch_Chen_2010）：新聞專業信念對 AI 採用意願具雙重作用——透過知覺威脅之規範性審慎路徑（負向間接效果 $-.153$）抑制使用，同時透過工具性嘗試路徑（正向直接效果 $+.194$）促進使用，二者在 96 位台灣政治記者樣本中近乎抵銷。

白話總結

本研究七個假設可總結為一句話：「專業信念越強的記者，一邊更警覺 AI 風險所以想拒用、一邊也更願意嘗試新工具所以想採用」。原提案以為這是單純的負向關係，本研究用資料證明背後有兩股反向力量同時運作——這比單一假設更能解釋為什麼台灣政治記者對 AI 的態度看起來模稜兩可（總效果接近 0，但拆開來兩條路徑都成立）。

自我效能（ASE）的調節作用方向與理論一致（互動項為正向），但本研究樣本量（96 人）不足以可靠偵測這個小至中等效果，故列為「方向支持但統計未達顯著」之待驗證假設。

d <- read.csv("journalist_ai_clean.csv")

# 1. 測量模型
mm <- constructs(
  composite("JPB", multi_items("JPB", 1:3)),
  composite("APT", multi_items("APT", 1:3)),
  composite("ASE", multi_items("ASE", 1:3)),

)

sm <- relationships(
  paths(from = "JPB", to = c("APT", "BI")),       # H1, H2
  paths(from = "ASE", to = "APT"),                 # H4
  paths(from = "JPB*ASE", to = "APT"),             # H6 互動
  paths(from = "APT", to = "BI")                   # H3
)

model <- estimate_pls(data = d, measurement_model = mm,

boot <- bootstrap_model(seminr_model = model, nboot = 5000, seed = 42)

附錄 B｜FAQ

Q1：JASP 找不到 PLS-SEM Modeling 子分析？

A：確認 JASP 版本 0.19.3+，並在右上角 ➕ 啟用 SEM 模組。若仍無，更新到 0.19.4 或用 R seminr 替代。

Q2：Bootstrap CI 跨 0 但分析 p < .05？

A：PLS bootstrap 在小樣本與弱指標下會出現 sign indeterminacy artifact。確認 JASP Sign change 設為 Construct level changes。若仍跨 0，以分析 p 為主，bootstrap CI 在限制中說明。

Q3：互動項加入後互動項的 t 值很大但 a1 / a2 變不顯著？

A：互動項與主效果共線性常見（即使做 mean-centering），看 VIF 是否 > 5；若是，改用 Orthogonalizing approach。

Q4：Index of Moderated Mediation 跟 conditional indirect 矛盾？

A：IMM 顯著表示 indirect effect 隨 moderator 變化；conditional indirect 在某些 moderator 水準可能仍跨 0（小樣本下檢力不足）。報告兩者並存，視 IMM 為主。

Q5：PLSpredict 在 JASP 跑不出來？

A：JASP 0.19.3 部分版本無此功能，用 R seminr 的 predict_pls() 替代。

Q6：刪 APT1 後結論變了怎麼辦？

A：分情況： - 變更顯著 → 報告兩版，主結果用刪 APT1 版本 - 結論一致 → 維持原版，刪 APT1 結果放附錄

Q7：JASP PLS-SEM 跟 CB-SEM 的語法差別？

A：兩者語法基底都是 lavaan 風格（=~ 表 indicator、:= 定義 derived parameter），但有關鍵差異： - CB-SEM：~ 表結構迴歸，~~ 表 covariance（兩者區分） - PLS-SEM：統一用單個 ~ 表所有構念對關係（不分結構與相關），且所有構念對都必須顯式列出 JASP 後端把同一段語法分別丟給 lavaan（CB-SEM）或 seminr（PLS-SEM），結果不同。 唯一差別：PLS-SEM 處理互動項需要在 Excel 預先計算 product indicator（見 Phase 5 Step 1），lavaan CB-SEM 也可同樣做或用 latent interaction（複雜度高）。

Q8：在 JASP PLS-SEM 中怎麼定義 Mode A vs Mode B？

A：JASP PLS-SEM Modeling 預設 Mode A（reflective）。若要改 formative（Mode B），通常透過模組選項面板，而非語法本身。本研究 4 個構念全為 reflective，無需切換。

Q9：Bootstrap 跑很慢？

A：5000 reps + BCa CI 在 N=96 下約 30-90 秒。若超過 5 分鐘，檢查： - 互動項是否導致估計不收斂（看 console 警告） - 是否勾了 Multi-group analysis（會把 boot 時間 ×2） - JASP 版本是否過舊（更新到 0.19.4+）
