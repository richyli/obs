個人任務：把一件常做的事，打磨成一個「專屬 AI 助手」

這是上午的總結任務：把前面學的（角色、背景、限制、範例、格式）全部收進一份長提示，再把它變成一個你以後點一下就能用的專屬助手——ChatGPT 的 GPT、Gemini 的 Gem、或 Claude 的 Project 都行。

✨ Take aways（你會帶走什麼）

你會做出一份可重複使用的長提示（把「每次都要重講的背景與規則」一次寫好），並學會怎麼把它存成一個專屬助手，以後處理同一類工作，開它、丟資料就好，不用每次從頭交代。

🧠 為什麼要做「長提示」？

前面練的是「一次一個 prompt」。但你有些工作是每週、每天都在重複的（擬同一類公文、回同一類詢問、寫會議紀錄）。與其每次重打背景，不如把「你是誰、規則是什麼、要什麼格式」一次寫成一份長提示，存起來變成專屬助手。之後只要餵當次的資料，它就照你訂好的規矩辦。

📝 跟著做

Step 1 選一件重複工作：挑一件你每週都要做好幾次、規則很固定的事（例：擬活動通知、回民眾陳情、把逐字稿整理成會議紀錄）。
Step 2 照骨架寫長提示：用下面的骨架，把這件事的角色、規則、格式、禁止事項一次寫清楚。
Step 3 在對話裡先測：把長提示貼進 AI，再丟一筆真實（去識別化的）資料，看它產出對不對，不對就回頭改長提示。
Step 4 存成專屬助手：測到滿意，照下面三家其中一家的做法，把長提示存成 GPT／Gem／Project。

📋 長提示骨架（複製後填空，這份是核心成果）

你是我的〔○○承辦助手〕，專門幫我〔擬育嬰留停陳核說明／回覆民眾陳情…〕。

【你的角色與立場】
- 我是〔單位／職稱〕，服務對象是〔民眾／上級／同仁〕。
- 語氣：〔正式但不冗長／誠懇不推諉〕。

【每次我會給你】
- 一筆〔申請案／陳情內容／逐字稿〕。個資我會先遮成〔〕，你不用追問當事人是誰。

【你要產出】
- 〔一段陳核說明／一則回覆／一份會議紀錄〕，包含：〔要件1〕〔要件2〕〔要件3〕。
- 格式：〔分段／表格／條列〕，長度〔X 字內〕。

【務必遵守（紅線）】
- 不要編造任何我沒給的數字、日期、文號，不確定的寫〔待補〕。
- 不要用〔業經、爰、俾〕這類過度文言的字。
- 不要洩漏或臆測任何個人資訊。

【範例（照這個語氣與格式）】
輸入：〔一筆範例資料〕
你的產出：〔一份理想範例〕

準備好了就說「請提供這次的資料」，等我貼。
關鍵：把「每次都一樣的規則」寫進長提示（角色、格式、紅線、範例），「每次不一樣的資料」之後再丟。這就是專屬助手的精神。

🚀 把長提示存成專屬助手（挑你用的那家）

ChatGPT建一個「GPT」
  1. 左側或右上點你的頭像／「探索 GPT」→ 「建立」(Create a GPT)（需要 Plus 付費版）。
  2. 切到 Configure（設定） 分頁，把上面的長提示貼進 Instructions（指令）欄。
  3. 填名稱（例「育嬰留停助手」）、簡介，可上傳範例檔當知識庫。
  4. 右側即時測試，滿意後按 Create／儲存，選「只有我」。以後在側欄點它就能用。
Gemini建一個「Gem」
  1. Gemini 左側找 「Gem 管理員」／「Gems」 → 新建 Gem。
  2. 把長提示貼進 「指示」(Instructions) 欄，填 Gem 名稱。
  3. 可上傳參考檔案。按 儲存／更新。
  4. 以後在 Gemini 左側點這個 Gem，直接進入帶好規則的對話。
Claude存成「Project」自訂指令
  1. Claude 左側 Projects → 新建 Project，命名。
  2. 把長提示貼進 Project 的 「自訂指令 / instructions」欄。
  3. 可把常用的範例、規則文件加進 Project 的知識庫。
  4. 之後在這個 Project 裡開對話，都會自動套用你的長提示。
進階：Claude 也支援 Skill（把一套流程打包），若你之後想做更自動化的版本可以再研究，今天先用 Project 就很夠。
三家共通提醒：① 建助手多半需要付費版（免費帳號可能只能用、不能建，那就先把長提示存在記事本，每次貼也行）。② 助手的知識庫別放真個資／機密——上傳等於交給平台。範例檔一律用去識別化的假資料。

✅ 完成標準

你有一份照著填、測過可用的長提示，並且（付費版）把它存成一個 GPT／Gem／Project，或（免費版）存進記事本當每次貼的範本。開它、丟一筆資料，就能穩定產出你要的東西。

🔀 延伸練習／自我加強

  • 幫自己第二件重複工作也做一個助手，慢慢累積一整套「個人 AI 工具箱」。
  • 把助手分享給同事共用（GPT／Gem 可設連結分享），讓整個科用同一套規則。
  • 回頭看 做成模板 練習，長提示其實就是「模板的加強版」。
