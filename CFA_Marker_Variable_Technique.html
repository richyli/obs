CFA Marker Variable Technique

#Research/Book

for CMB Common method bias

CFA Marker Variable Technique（驗證性因素分析標記變數法） 是目前解決共同方法變異（CMB）最嚴謹、最具說服力的「統計控制」手段之一。 相較於 Harman's Single Factor Test 只能「診斷」有無問題，Marker Variable Technique 能夠進一步「控制」並「剔除」這些誤差，看看在排除誤差後，原本的研究假設是否依然成立。 以下是針對博士班資格考與回應 Reviewer 質疑的詳細解析：

一、 核心邏輯：什麼是「標記變數 (Marker Variable)」？

這個方法的精髓在於引入一個「理論上與原本研究變項毫無關聯」的變數，稱之為「標記變數」。

  • 邏輯假設：

    1. 既然這個標記變數（例如：「對藍色的喜好程度」）與你的研究變數（例如：「工作滿意度」）在理論上毫無關係，那麼它們之間的相關係數理應為 0。
    2. 如果統計跑出來發現它們之間竟然有顯著相關（例如 $r = 0.3$），那麼這 $0.3$ 的相關性肯定不是來自理論，而是來自「方法偏差」（例如：受試者當下的情緒、填答風格、問卷排版等）。
    3. 我們可以把這 $0.3$ 當作「噪音（CMB）」，在統計模型中將其扣除，剩下的才是「真實的關係」。

二、 操作步驟：三階段模型比較法

這是博士生必須能描述的流程（通常引用 Williams, Hartman, & Cavazotte, 2010 或 Lindell & Whitney, 2001）。 我們需要在 SEM 軟體（如 AMOS, Mplus, SmartPLS）中建立不同的模型進行比較：

步驟 1：建立 Baseline Model（基準模型）
  • 這是正常的 CFA 模型，包含自變項、依變項與標記變數。
  • 關鍵設定：允許自變項與依變項之間有相關，但強迫標記變數與其他變項的相關係數為 0（因為理論上無關）。
步驟 2：建立 Method-C Model（共同方法模型）

  • 在此模型中，加入一個潛在變項稱為「方法因子 (Method Factor)」。

  • 關鍵設定：

    1. 用標記變數的題目來定義這個方法因子。
    2. 讓這個方法因子去影響（指向）模型中所有的題目（包含自變項與依變項的題目）。
    3. 這意味著：每一道題目的分數，現在被拆解成「原本構面的影響」+「方法因子的影響（誤差）」。
步驟 3：比較與判讀

比較上述兩個模型的適配度（Chi-square difference test）：

  1. 檢驗 CMB 是否存在：

    • 如果 Model-C（有方法因子）的適配度顯著優於 Baseline Model，代表「方法因子」確實解釋了相當大比例的變異量。$\rightarrow$ 承認資料存在 CMB。

  2. 檢驗 CMB 是否致命（關鍵救命步驟）：

    • 在控制了方法因子後，重新檢視自變項與依變項的路徑係數（Path Coefficients）。
    • 如果原本顯著的路徑，在扣除方法變異後依然顯著，這就是研究者的勝利。
    • 結論：「雖然存在些微的共同方法變異，但在統計控制後，不影響本研究的主要結論。」

三、 為什麼 Reviewer 喜歡這個方法？（與 Harman's 的比較）

特性 Harman's Single Factor Test CFA Marker Variable Technique
性質 診斷性（只能看有沒有病） 補救性（有病可以試著治療）
嚴謹度 低（粗略的 EFA） 高（精確的 SEM/CFA）
檢測邏輯 假設單一因子解釋 >50% 才有問題 只要有非理論的共變異數即被捕捉
結果處理 若沒過，文章通常會被拒稿 若沒過，可以控制誤差後證明假設仍成立，保住文章

四、 挑選「標記變數」的眉角（陷阱題）

博士生常被問：「那你怎麼選這個標記變數？」如果選錯，整個檢定無效。

  • 正確選法：選擇一個與研究主題完全無關的變數。

    • 例子：若研究「科技接受度（TAM）」，可以選「時尚意識（Fashion Consciousness）」或「對天氣的態度」作為標記變數。

  • 錯誤選法：選擇一個「看起來有點像」的變數。

    • 錯誤例子：若研究「員工滿意度」，選了「組織承諾」當標記變數。

    • 後果：因為這兩者理論上本來就有相關，你把它當作誤差扣掉，會把「真實的解釋力」也扣掉（Over-correction），導致原本顯著的假設變成不顯著。

五、 博士資格考作答範例（話術）

若題目問：「如何嚴謹處理共同方法變異？」建議回答架構如下：

「雖然 Harman's Single Factor Test 是常見的初步檢測，但考量其敏感度不足且無法分離誤差變異，本研究建議採用更嚴謹的 CFA Marker Variable Technique。

具體作法為：在問卷設計階段預先置入一個與研究構面理論無關的『標記變數』（如：社會期許量表或無關態度題）。

在分析階段，我將比較『基準模型』與『加入方法因子模型』的適配度差異。若發現方法因子顯著改善了模型適配度，我將進一步檢視在控制該方法變異後，主要研究假設的路徑係數是否依然顯著。這能確保研究結論的穩健性（Robustness），有效回應 Reviewer 對於自填式問卷偏差的質疑。」

總結

Marker Variable Technique 是將「黑盒子（未知的誤差）」變成「白盒子（可測量的誤差）」的過程。它不僅能防禦攻擊，更是證明研究結果具有強韌性（Robustness）的高級技巧。

這是一個非常專業的防禦策略。您提到的應該是 "Marker Variable"（標記變數）（有時因為拼寫相近會被誤稱為 Market Variable，但在 CMB 脈絡下我們稱之為 Marker）。

在博士論文或高品質期刊中，僅僅「放了」這個變數是不夠的，您必須透過統計數據證明「它發揮了作用」且「CMB 不嚴重」。

以下是檢驗 Marker Variable 數值的完整三階段流程：

第一階段：相關係數矩陣檢視 (The Eye-ball Test)

這是最直觀的第一步。

  • 操作：跑出所有變數（包含您的自變數 X、依變數 Y 與 Marker Variable M）的 Pearson 相關係數矩陣。

  • 檢驗標準：

    1. 理論上無關：Marker Variable 與您的 X 或 Y 之間的相關係數 ($r$) 應該要 非常低 且 不顯著 (non-significant)。

    2. 理想數值：$r$ 最好接近 0 (例如 0.01 ~ 0.10)。

  • 判讀：

    • 如果 Marker 跟您的主要變數相關係數高達 0.3 或 0.4，代表選錯 Marker 了（它跟構念有關），或者 CMB 已經嚴重到把不相關的東西都拉在一起了。

    • 如果相關係數很低（例如 $r = 0.05$），這是好消息，初步證明沒有嚴重的共同方法變異。

Example

社交媒體與衝動購買研究 (Arghashi 2025) Arghashi 2025 - Compulsive Social Media Use.pdf ◦ 標記變數： 研究者選擇了 「每天花在社交媒體上的平均時間」（the average time spent on social media per day） 作為標記變數。 ◦ 操作方式： 他們將此變數視為與模型中其他構念（如強迫性社交媒體使用、衝動購買行為等）不相關的變數放入 SEM 模型中進行估計。 ◦ 結果說明： 分析結果顯示，這個標記變數與其他任何構念之間沒有顯著的相關性（相關係數 ≤0.10）。這意味著數據中並沒有因为測量方法本身而產生普遍的高相關性，從而證實 CMB 在該研究中不是嚴重的問題。

例子二：手機遊戲（Pokémon GO）行為研究 (How to Achieve Goals in Digital Games -- An Empirical Test of a Goal-Oriented Model in Pokemon GO, Kwak 2022)

◦ 標記變數： 研究者加入了一個理論上與遊戲目標完全無關的變數——「時尚涉入度」（fashion involvement）。
◦ 操作方式： 他們測試了該變數與研究中其他變數（如目標可行性、遊戲內付費、目標導向的努力等）之間的相關性。
◦ 結果說明： 預期中該變數與研究構念不應有相關。結果顯示，平均相關係數接近於 0 (r=0.04)。具體來看，它與「遊戲內付費」的相關係數僅為 0.01，與「目標導向努力」的相關係數為 -0.02。基於這些極低的相關性，研究者得出結論，CMB 不太可能造成問題。

第二階段：Lindell & Whitney (2001) 校正法

這是最經典的數學檢驗法，用來回答：「如果扣掉這個 Marker 抓到的雜訊，我的研究假設還成立嗎？」

  • 邏輯：假設 Marker Variable 與其他變數之間的相關，純粹是來自於 CMB（因為理論上它們不該相關）。我們把這個相關係數當作 「誤差基線 ($r_M$)」。

  • 操作步驟：

    1. 找出 Marker Variable 與所有實質變數中 「最小的正相關係數」，記為 $r_M$（這代表 CMB 的最小影響力）。

    2. 使用 偏相關 (Partial Correlation) 公式，將這個 $r_M$ 從您原本的 X-Y 相關係數 ($r_{XY}$) 中扣除。

    3. 公式 (校正後的相關)：

      $$r_{XY.M} = \frac{r_{XY} - r_M}{1 - r_M}$$

  • 檢驗判決：

    • 計算出 $r_{XY.M}$ 後，檢查它的 t 值 或 P 值。

    • 過關：如果校正後，X 對 Y 的相關 依然顯著，代表 CMB 雖然存在，但不足以推翻您的研究結論。

    • 失敗：如果校正後變不顯著，代表原本的顯著都是 CMB 造成的假象。

### 1. 檢驗邏輯：Lindell & Whitney (2001) 檢定法 我們當初在 VBA 裡設計 **Blue (Marker)** 這個變數時，故意讓它跟壓力 (Stress) 或健康 (Health) **理論上毫無關係**。 - **如果沒有 CMB**：受試者很理智，填答時不會因為「習慣性勾選」或「當下心情」而讓所有分數一起變高。所以 Blue 跟其他變數的相關係數應該 **接近 0**。 - **如果有 CMB**：受試者填答很隨便（或受情緒影響），導致所有分數都「糾纏」在一起。這時 Blue 跟 Stress 的相關係數就會 **異常地高 (例如 > 0.3)**。 ### 2. 您的數據判讀 請看您截圖中的 **Marker** 這一欄： |**變數對 (Pair)**|**相關係數 (Correlation)**|**判讀**| |---|---|---| |**Marker vs. Stress**|**-0.035**|極低 (幾乎是 0) ✅| |**Marker vs. Support**|**0.099**|很低 (不到 0.1) ✅| |**Marker vs. Mental**|**-0.019**|極低 (幾乎是 0) ✅| |**Marker vs. Physical**|**0.076**|很低 (不到 0.1) ✅| **結論：** 所有的相關係數都微乎其微（最大也才 0.099）。這證明了： > 「即使受試者使用同一份問卷填答，他們對『藍色的喜好』與『壓力/健康』的填答模式是**完全獨立**的。」 這直接排除了「填答方法造成所有變數假性相關」的可能性。 --- 這是一個非常專業的問題！您提到的是 **Lindell & Whitney (2001)** 提出的 **「相關係數校正法 (Correlation Adjustment)」**。 這個方法的邏輯是：**「如果我們假設 Marker Variable (標記變數) 與其他變數的相關係數，純粹是由共同方法變異 (CMB) 造成的，那我們就把這個『污染值』從所有其他的相關係數中扣掉。」** 由於 JASP 沒有內建這個「一鍵校正」按鈕，您需要**手動計算**（或是用 Excel）。別擔心，公式非常簡單。 以下是執行的 **三步驟 SOP**： --- ### 第一步：抓出「代理污染值」 ($r_M$) 請看您剛剛跑出來的相關矩陣表格。 我們要從 **Marker (Blue)** 與其他變數的相關係數中，找出一個代表 CMB 強度的數值。 - 或者為了嚴格測試（Sensitivity Analysis），我們會挑選 **「第二小的正相關」** 甚至是 **「最大的正相關」** 來做壓力測試（看看就算扣掉這麼多，結果還顯不顯著）。 - **您的決定**： - 因為您的相關都很小，且有負值（通常視為 0 污染）。 - 讓我們採用最嚴格的標準：選最大的那個正相關 **$r_M = 0.099$** (Marker vs. Support) 當作污染值。 - 第三階段：CFA 模型法 (CFA with Marker Variable)

這是目前最嚴謹、Reviewer 最喜歡的方法（特別是如果您用 AMOS 或 Mplus）。

  • 操作邏輯：

    1. 建立一個 CFA 模型，包含所有實質構念與 Marker Variable。

    2. 模型 A (Baseline)：讓所有構念依標準方式自由相關。

    3. 模型 B (Method Model)：

      • 加入 Marker Variable 作為一個潛在因子。

      • 畫箭頭從 Marker 指向 「每一個」 實質變數的題目 (Indicators)。

      • 將 Marker 與其他構念的相關設為 0 (Orthogonal)。

  • 檢驗數值：

    • 比較 模型 A 與 模型 B 的 標準化路徑係數 (Standardized Regression Weights)。

  • 判決標準：

    • 如果加入 Marker 後，原本 X $\rightarrow$ Y 的結構係數改變 小於 0.2 (或差異不顯著)，則宣稱 CMB 不嚴重。

    • 查看 Marker 指向各題目的 Loading，如果普遍很低 (e.g., < 0.2)，代表方法變異解釋力很低。

總結：如何在論文中報告？

您可以在「方法論」或「結果」章節中這樣寫：

"To assess the potential threat of Common Method Bias (CMB), a Marker Variable (theoretically unrelated to the substantive constructs) was included in the survey.

  1. Correlation Analysis: The correlations between the marker variable and the study variables were low and non-significant (ranging from 0.01 to 0.08), indicating minimal method variance.

  2. Lindell & Whitney (2001) Test: We applied the marker variable technique to adjust the correlations. Even after controlling for the method variance proxied by the marker ($r_M = 0.05$), all significant relationships in the hypothesized model remained significant.

Therefore, CMB is not a pervasive issue in this study."

一句話心法：

Marker Variable 的數值檢驗重點在於 「比較」 —— 比較「扣除它之前」與「扣除它之後」，您的結論是否依然穩如泰山。
