CFA Marker Variable Technique

#Research/Book　#CMB　#marker_variable　#measurement_model　#SEM　#PLS_SEM

for CMB Common method bias

CFA Marker Variable Technique（驗證性因素分析標記變數法） 是目前處理 CMB Common method bias 最嚴謹、最具說服力的「統計控制」手段。相較於 Harman's Single Factor Test 只能「診斷」有無問題，Marker Variable Technique 能進一步「控制」並「剔除」方法變異，檢驗在排除誤差後原本的研究假設是否仍成立。

它在 CMB 三層級防禦中位居「控制」層，下游搭配 Lindell Exercise 進行事後敏感度校正，構成完整的偵測—控制—校正三段式（Williams, Hartman & Cavazotte, 2010；Lindell & Whitney, 2001）。

一、核心邏輯：什麼是「標記變數 (Marker Variable)」？

精髓在於引入一個理論上與原本研究變項毫無關聯的變數，稱為「標記變數」。

  • 邏輯假設：
    1. 既然標記變數（例如「對藍色的喜好程度」）與研究變數（例如「工作滿意度」）在理論上毫無關係，那麼它們的相關係數理應為 0
    2. 若統計跑出來竟有顯著相關（例如 $r = 0.3$），這 $0.3$ 不可能來自理論，而是來自方法偏差（受試者當下的情緒、填答風格、問卷排版等）
    3. 我們將這 $0.3$ 視為「噪音（CMB）」，在統計模型中扣除，剩下的才是「真實關係」

二、操作步驟：三階段模型比較法（Williams, Hartman & Cavazotte, 2010）

博士生必須能描述的標準流程，於 SEM 軟體（AMOS、Mplus、SmartPLS）中建構並比較三組巢套模型：

步驟 1：Baseline Model（基準模型）

  • 正常 CFA 模型，包含自變項、依變項與標記變數
  • 關鍵設定：允許自變項與依變項之間有相關，但強迫標記變數與其他變項的相關係數為 0（理論上無關）

步驟 2：Method-C Model（共同方法模型）

加入一個潛在變項稱為「方法因子 (Method Factor)」：

  1. 用標記變數的題目來定義這個方法因子
  2. 讓方法因子去影響（指向）模型中所有題目（包含自變項與依變項）
  3. 每道題目的分數現在被拆解成「原本構面的影響」+「方法因子的影響（誤差）」

步驟 3：比較與判讀（Chi-square difference test）

  1. 檢驗 CMB 是否存在：若 Method-C Model 適配度顯著優於 Baseline Model，代表方法因子確實解釋了相當大比例的變異 → 承認資料存在 CMB
  2. 檢驗 CMB 是否致命（救命步驟）：在控制方法因子後，重新檢視自變項—依變項的路徑係數。若原本顯著的路徑在扣除方法變異後依然顯著，可宣稱「雖存在些微 CMB，但不影響本研究主要結論」

三、為什麼 Reviewer 偏好此方法？（與 Harman's 對比）

特性 Harman's Single Factor Test CFA Marker Variable Technique
性質 診斷性（只能看有無病） 補救性（有病可試著治療）
嚴謹度 低（粗略 EFA） 高（精確 SEM/CFA）
檢測邏輯 假設單一因子解釋 >50% 才有問題 任何非理論的共變異數都被捕捉
結果處理 若沒過，文章通常被拒稿 若沒過，可控制誤差後證明假設仍成立，保住文章

四、挑選「標記變數」的眉角（陷阱題）

博士生常被問：「你怎麼選這個標記變數？」選錯則整個檢定無效。

  • 正確選法：選擇與研究主題完全無關的變數
    • 範例：研究「科技接受度（TAM）」可選「時尚意識（Fashion Consciousness）」或「對天氣的態度」
    • 經典 Marker：Simmering et al. (2015) 提出的「對藍色的態度（Attitude Toward the Color Blue）」，因大多數研究主題（領導力、行銷）都與此無關
  • 錯誤選法：選擇「看起來有點像」的變數
    • 錯誤範例：研究「員工滿意度」卻選「組織承諾」當標記
    • 後果：兩者理論上本就有相關，當作誤差扣掉會把「真實解釋力」也扣掉（Over-correction），導致原本顯著的假設變成不顯著

五、數值檢驗的三階段流程（事後驗證）

僅僅「放了」Marker Variable 並不夠，必須透過統計數據證明「它發揮了作用」且「CMB 不嚴重」。

第一階段：相關係數矩陣檢視（Eye-ball Test）

最直觀的第一步。

  • 操作：跑出所有變數（自變數 X、依變數 Y、Marker M）的 Pearson 相關係數矩陣
  • 檢驗標準：
    1. 理論上無關：Marker 與 X、Y 之間的 $r$ 應非常低且不顯著
    2. 理想數值：$r$ 接近 0（例如 0.01 ~ 0.10）
  • 判讀：
    • $r \geq 0.3$：選錯 Marker 或 CMB 嚴重
    • $r \leq 0.1$：好消息，初步證明無嚴重共同方法變異
跨研究實證

Example 1：社交媒體與衝動購買（Arghashi, 2025） Arghashi 2025 - Compulsive Social Media Use.pdf

  • 標記變數：「每天花在社交媒體上的平均時間（average time spent on social media per day）」
  • 操作方式：將其視為與模型中其他構念（強迫性社交媒體使用、衝動購買行為）不相關的變數放入 SEM 模型
  • 結果：標記變數與其他任何構念之間沒有顯著相關（$r \leq 0.10$），數據中沒有因測量方法本身而產生普遍高相關性，CMB 不是嚴重問題

Example 2：手機遊戲（Pokémon GO）行為研究 How to Achieve Goals in Digital Games -- An Empirical Test of a Goal-Oriented Model in Pokemon GO, Kwak 2022

  • 標記變數：「時尚涉入度（fashion involvement）」——理論上與遊戲目標完全無關
  • 結果：平均相關係數接近 0（$r = 0.04$）；與「遊戲內付費」的相關僅 0.01，與「目標導向努力」為 -0.02 → CMB 不太可能造成問題

第二階段：Lindell & Whitney (2001) 校正法

最經典的數學檢驗法（詳見 Lindell Exercise），回答：「扣掉這個 Marker 抓到的雜訊後，研究假設還成立嗎？」

  • 邏輯：假設 Marker 與其他變數的相關純粹來自 CMB，將此係數作為誤差基線 ($r_M$)
  • 操作步驟：
    1. 找出 Marker 與所有實質變數中最小的正相關係數作為 $r_M$（CMB 的最小影響力代理值）
    2. 套用偏相關公式從原本的 $r_{XY}$ 中扣除： $$r_{XY.M} = \frac{r_{XY} - r_M}{1 - r_M}$$
    3. 檢查 $r_{XY.M}$ 的 t / p 值
  • 判決：
    • 過關：校正後 X-Y 相關依然顯著 → CMB 雖存在但不足以推翻結論
    • 失敗：校正後變不顯著 → 原本的顯著皆為 CMB 假象

第三階段：CFA 模型法（CFA with Marker Variable）

最嚴謹、Reviewer 最偏好的方法（特別是用 AMOS 或 Mplus）。本質上即第二節「三階段模型比較法」的數值化判讀。

  • 操作邏輯：
    1. 建立 CFA 模型，包含所有實質構念與 Marker
    2. 模型 A (Baseline)：所有構念依標準方式自由相關
    3. 模型 B (Method Model)：
      • 加入 Marker 作為一個潛在因子
      • 畫箭頭從 Marker 指向每一個實質變數的題目（Indicators）
      • 將 Marker 與其他構念的相關設為 0（Orthogonal）
  • 檢驗數值：比較模型 A 與 B 的標準化路徑係數（Standardized Regression Weights）
  • 判決標準：
    • 加入 Marker 後，原本 X $\rightarrow$ Y 的結構係數改變小於 0.2（或差異不顯著）→ 宣稱 CMB 不嚴重
    • Marker 指向各題目的 Loading 普遍很低（例如 < 0.2）→ 方法變異解釋力低

六、口試作答與論文書寫範例

口試話術

若題目問：「如何嚴謹處理共同方法變異？」建議架構：

「雖然 Harman's Single Factor Test 是常見的初步檢測，但考量其敏感度不足且無法分離誤差變異，本研究採用更嚴謹的 CFA Marker Variable Technique。

具體作法為：在問卷設計階段預先置入一個與研究構面理論無關的『標記變數』（如社會期許量表或無關態度題）。在分析階段，比較『基準模型』與『加入方法因子模型』的適配度差異。若方法因子顯著改善模型適配度，進一步檢視在控制該方法變異後，主要研究假設的路徑係數是否依然顯著。這能確保研究結論的穩健性（Robustness），有效回應 Reviewer 對於自填式問卷偏差的質疑。」

論文方法／結果章節寫法

"To assess the potential threat of Common Method Bias (CMB), a Marker Variable (theoretically unrelated to the substantive constructs) was included in the survey.

  1. Correlation Analysis: The correlations between the marker variable and the study variables were low and non-significant (ranging from 0.01 to 0.08), indicating minimal method variance.
  2. Lindell & Whitney (2001) Test: We applied the marker variable technique to adjust the correlations. Even after controlling for the method variance proxied by the marker ($r_M = 0.05$), all significant relationships in the hypothesized model remained significant.

Therefore, CMB is not a pervasive issue in this study."

七、與其他 CMB 防禦方法的位置

層級 方法 角色
1. 診斷 Harman's Single Factor Test 看有沒有問題；不能修正
2. 控制 CFA Marker Variable Technique 用 SEM 控制方法變異
3. 校正 Lindell Exercise 數學校正後測試結論穩健性

並與量測模型其他效度檢定共構： - 共線性連動：VIF Variance Inflation Factor < 3.3 的 Full Collinearity Test 為平行證據；同時超標則 Multicollinearity 共線性 與 CMB 同時警訊 - 區別效度連動：HTMT（< 0.85/0.90）、Discriminant Validity 區別校度、Fornell-Larcker 確認構念實質可分；HTMT 偏高有時來自 CMB 而非真構念重疊

總結

Marker Variable Technique 是把「黑盒子（未知誤差）」變成「白盒子（可測量誤差）」的過程。它不僅能防禦攻擊，更是證明研究結果具有強韌性（Robustness）的高級技巧。

一句話心法：Marker Variable 的數值檢驗重點在於「比較」——比較「扣除前」與「扣除後」，結論是否依然穩如泰山。

相關概念 - 上位概念：CMB Common method bias - 同層方法：Harman's Single Factor Test、Lindell Exercise - 共線性脈絡：VIF Variance Inflation Factor、Multicollinearity 共線性 - 區別效度脈絡：HTMT、Discriminant Validity 區別校度、Fornell-Larcker
