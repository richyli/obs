會動手的 AI（Agentic）：什麼時候該從「聊天」升級成「動手」

這是一頁概念總覽，不用動手。前面所有練習用的都是「對話式 AI」——你打字、它回你文字，動作你自己來。這頁講的是下一個層次：會直接讀你的檔案、幫你動手做事的 AI（agentic），以及一個實用的判斷力：什麼樣的公務工作，該從對話式升級到會動手的。

✨ Take aways（你會帶走什麼）

你會分得清「對話式」與「會動手（agentic）」的差別，看得懂一件公務工作該用哪一種，並知道升級到會動手的工具時，有哪些資安界線一定要守。

🪜 一句話分清楚兩者

對話式 AI（前面都在用的）會動手的 AI（agentic）
它做什麼回你一段文字直接讀你的檔、改你的檔、跑一整套流程
動作誰做你自己（複製、貼上、對回 Word）它做，你在旁邊看、必要時喊停
一次能處理你貼進去的那一段整個資料夾、幾十份檔案
代表工具ChatGPT、Claude、Gemini 網頁版Claude Code、Copilot in Office、連接器（MCP）
💡 一個生活比喻：對話式像一位很會寫的顧問——你問他、他給你建議，執行要你自己來；會動手的像一位資深助理——你交代一件事，他直接去翻檔案、整理、做出來給你看。

🎯 判斷表：這件公務工作，該用哪一種？

不是每件事都要動用 agentic。用一個簡單原則判斷：牽涉到「一整批檔案」「跨檔比對」「要真的產出檔案」的，才值得升級；單純生一段文字的，對話式就好。

公務工作用哪種為什麼
擬一份公文、一則通知、一段公告對話式單次文字生成，殺雞不用牛刀
把一份長文件摘要成重點對話式可一份還好；但若要一次讀整個資料夾就該用會動手的
兩份法規／契約並排逐條比對會動手對話式貼不進兩份長文件、也做不出並排標差異 → 見 法規比對
一整批民眾留言分類、統計、產表會動手整批 CSV 資料，對話式一次只能貼一小段 → 見 建言分析
一疊舊公文一次全轉白話會動手讀整個資料夾批次改寫，對話式要一份份貼
行事曆排會、雲端硬碟找檔彙整會動手要它實際去操作你的工具，不只給建議 → 見 Agentic Demo

🧭 三頁怎麼分工

這一區有三頁，各看一個面向，建議照順序看：

  • 這頁（概念）：搞懂對話式 vs 會動手的差別、什麼時候該升級。
  • Agentic Demo（實例現場）：看老師實際示範「會動手的 AI」做三件事，感受它跟對話式的落差。
  • 桌面版工具介紹（工具清單）：認識 Claude Desktop、Copilot、Claude Code 等具體工具，以及該不該裝。

🔧 公務最有感的三個「會動手」場景

① 法規／契約並排比對：修法前後兩版並排，逐條標出「刪了什麼、加了什麼、改了什麼」。承辦手動比一整天，會動手的 AI 幾分鐘給你一張對照表。
② 一整批文件彙整：把一個資料夾的幾十份回覆、報告、會議紀錄，一次讀完、彙整成一張總表或一份摘要。
③ 重複流程自動化：每個月都要做的同一套整理（把 A 檔的東西挑出來、套進 B 格式、產出 C 報表），交代一次，之後照跑。
這三個場景在對應的練習頁（法規比對、長文件摘要、建言分析）裡，都有一個「🤖 用 Claude Code 可以這樣放大」的區塊，講具體怎麼做。

🤔 我現在就需要嗎？

用三個問題判斷：

  • 我常常要「把好幾個檔案的東西湊起來」嗎？是 → 會動手的能幫你自動彙整。
  • 我有一套每個月重複、跨檔案的固定流程嗎？是 → 那正是 agentic 最能省時的地方。
  • 以上都沒有？——那對話式＋一份好的長提示，已經能解決八成公務需求。會動手的是「工作量大了再升級」的選項，不是必須。

🔐 升級前必看的資安界線

會動手的 AI 威力更大，風險也更大——因為它能真的碰到你的檔案。務必：
  • 機關核可才裝：公務電腦裝軟體、開連接器，先確認資訊單位政策，別自己亂裝。
  • 只授權必要範圍：能讀整個雲端硬碟不代表該全開，只授權你真的要用的資料夾。
  • 個資／機密仍是紅線：工具能讀不代表可以讓它處理敏感資料；去識別化與機關規範照樣適用（回想 去識別化那一課）。
  • 它動手前你要看得到、能喊停：好的 agentic 工具會在真的改檔前讓你確認，別讓它全自動跑你沒看過的動作。

📌 帶走一句話

AI 不只是「網頁上聊天」——它正在變成會讀你檔案、替你動手的工作夥伴。判斷原則很簡單：要生一段文字，用對話式；要處理一整批檔案、跨檔比對、產出檔案，就是會動手的 AI 上場的時候。先把對話式＋好提示練熟，等你發現自己天天在重複搬檔、彙整，就是升級的訊號。
