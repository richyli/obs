Lavaan

這是一份 lavaan (Latent Variable Analysis) 套件的核心語法速查表。lavaan 的模型語法是以 字串 (String) 的形式撰寫，透過不同的運算符號來定義變項之間的關係。

1. 核心運算符號 (Operators)

這是建構模型最基礎的符號，請務必熟悉：

Formative

X <~ X1 + X2 + X3

符號 意義 說明 範例
=~ 測量 (Measured by) 用於定義潛在變項 (Latent Variable) F1 =~ x1 + x2 + x3 (F1 由 x1, x2, x3 測量)
~ 迴歸 (Regressed on) 用於定義路徑、因果關係 (Path) y ~ x1 + x2 (y 被 x1 和 x2 預測)
~~ 共變/變異 (Covariance) 相關性或殘差變異 x1 ~~ x2 (x1 與 x2 相關)；x1 ~~ x1 (x1 的變異數)
~1 截距 (Intercept) 平均數或截距項 x1 ~ 1 (估計 x1 的截距/平均數)
| 閾值 (Threshold) 用於處理類別/有序變項
:= 定義參數 (Defined as) 定義新的參數 (常用於中介效果) ab := a * b (計算間接效果)
== 限制 (Constraint) 設定參數相等限制 p1 == p2

2. 完整模型語法範例 (Cheat Sheet)

您可以將以下語法結構複製到 R 中進行修改。

A. 基本 CFA (驗證性因素分析) 與 SEM (結構方程模型)

R

model <- '
  # 1. 測量模型 (Measurement Model) - 定義潛在變項
    Visual   =~ x1 + x2 + x3      # 潛在變項 Visual 由 x1-x3 測量
    Textual  =~ x4 + x5 + x6      # 預設會將第一個指標的負荷量固定為 1
    Speed    =~ x7 + x8 + x9

  # 2. 結構模型 (Structural Model) - 定義迴歸路徑
    Visual   ~ Textual + Speed    # Visual 被 Textual 和 Speed 預測
    Speed    ~ Textual            # Speed 被 Textual 預測

  # 3. 殘差相關 (Residual Correlations)
    x1 ~~ x2                      # 允許 x1 與 x2 的殘差相關
    x7 ~~ x8

  # 4. 固定參數 (Fixing Parameters)
    Visual =~ 1*x1                # 顯式固定因素負荷量為 1 (雖然預設已有)
    x2 ~~ 0.5*x2                  # 將 x2 的殘差變異數固定為 0.5
'
B. 中介效果 (Mediation) 與 參數標籤 (Labeling)

若要測試中介效果（如 Bootstrap 檢定），需要使用標籤（label）與 := 運算子。

R

mediation_model <- '
  # 直接路徑 (給予標籤 a, b, c)
    M ~ a*X           # X 到 M 的路徑，係數標記為 a
    Y ~ b*M + c*X     # M 到 Y 標記為 b；X 到 Y (直接效果) 標記為 c

  # 定義新參數 (計算間接與總效果)
    indirect := a * b       # 間接效果 (a 乘 b)
    total    := c + (a*b)   # 總效果 (直接 + 間接)
'
C. 多群組分析 (Multiple Groups) 的限制語法

在進行測量恆等性 (Measurement Invariance) 檢定時，常需要對不同群組設定標籤。

R

group_model <- '
  # 設定因素負荷量：使用 vector c() 針對不同群組設定
  # c(群組1參數, 群組2參數)

  F1 =~ c(L1, L1)*x1 +    # 強制兩群組 x1 的負荷量相等 (都叫 L1)
        c(L2, L2)*x2 +    # 強制兩群組 x2 的負荷量相等 (都叫 L2)
        c(L3a, L3b)*x3    # 允許兩群組 x3 的負荷量不同 (分別叫 L3a, L3b)
'

3. 常用的執行函數 (Functions)

定義好字串模型後，需搭配正確的函數來執行分析：

  1. cfa(): 專門用於驗證性因素分析 (預設 std.lv = FALSE, 潛在變項間預設相關)。

  2. sem(): 用於完整的結構方程模型 (預設 fixed.x = TRUE)。

  3. growth(): 用於潛在成長模型 (Growth Curve Models)。

標準執行程式碼：

R

# 假設您的資料框叫做 Data
fit <- sem(model, data = Data)

# 查看結果 (包含標準化係數、R-square、配適度指標)
summary(fit, standardized = TRUE, fit.measures = TRUE, rsquare = TRUE)

# 取得修改指標 (Modification Indices)，例如 mi > 10
modindices(fit, sort = TRUE, minimum.value = 10)

4. 常見設定參數說明

在 sem() 或 cfa() 函數中，幾個常用的參數設定：

  • std.lv = TRUE: 將潛在變項的變異數固定為 1 (標準化潛在變項)，而不是將第一個指標固定為 1。

  • missing = "fiml": 使用全訊息最大概似估計法 (FIML) 處理遺漏值。

  • estimator = "MLR": 使用 Robust Maximum Likelihood，適用於資料非常態 (Non-normal) 的情況 (提供 Robust 標準誤與 Scaled Chi-square)。

  • group = "Gender": 指定分組變項進行多群組分析。

5. JASP PLS-SEM 的 lavaan 語法（六大模型範本）

JASP 0.19+ 的 SEM → PLS-SEM 模組使用 seminr 後端，Model syntax 框接受 lavaan 風格的核心語法（=~、~、~~），但有兩個重要限制必須先理解，否則整個模型會跑錯或衍生參數失效：

⚠️ JASP 與 R lavaan 的關鍵差異

語法 R lavaan JASP PLS-SEM (seminr)
=~、~、~~ ✅ ✅
a*X 路徑標籤 ✅ 標籤 ❌ 不是標籤——seminr 解讀為「母體真值（population value）」，部分路徑加 * 會跳警告 Only a subset of population values given
indirect := a*b 衍生參數 ✅ ❌ 失效（標籤未定義，此段被忽略）
Bootstrap CI ✅ ✅（在 Estimation 面板勾選）
多群組 group= 參數 ✅ Grouping Variable 框
互動項 可用 : 或乘積指標 ✅ 必須用乘積指標法（pre-compute 後當新構念）

JASP-only 工作流的鐵律：所有需要間接效果、IMM、conditional indirect 的數字，必須從 Regression Coefficients 表抄出來，到 Excel 用 Sobel 公式手算；不能依賴 lavaan 的 :=。

此外：JASP 還要求所有要分析的變項先拖入 Model 面板的 Variables / Indicators 框，否則 bootstrap 跑不出結果（seminr 不會自動掃描 syntax 內的變項）。

以下六個範例皆以「JPB（專業信念）→ APT（威脅感）→ BI（使用意願）+ ASE（自我效能）」這組變項為例，可直接貼入 JASP Model syntax 框。

範例 A — 一般模型（純 CFA 量測模型）

驗證 4 個構念的因素結構，無結構路徑。

# Pure CFA: 只測量、不跑結構
JPB =~ JPB1 + JPB2 + JPB3
APT =~ APT1 + APT2 + APT3
ASE =~ ASE1 + ASE2 + ASE3
BI  =~ BI1  + BI2  + BI3
  • 看什麼：Factor Loading（≥ .70）、AVE（≥ .50）、HTMT（< .85）、Cronbach's α / rho_A / $\rho_c$（≥ .70）
  • 此階段不看：β、$R^2$、間接效果（這些屬結構模型）
  • Output 面板必勾：Reliability measures、Observed construct correlations

範例 B — 主效果模型（Direct Effects）

H1 / H4：JPB 與 ASE 對 BI 與 APT 的直接效果。

# Measurement
JPB =~ JPB1 + JPB2 + JPB3
APT =~ APT1 + APT2 + APT3
ASE =~ ASE1 + ASE2 + ASE3
BI  =~ BI1  + BI2  + BI3

# Structural（無中介、無調節）
APT ~ JPB + ASE
BI  ~ JPB + ASE
  • 看什麼：每個 path 的 β、95% CI、p、VIF Variance Inflation Factor（Inner VIF < 3.3）
  • 論文符號：Outcome=APT, Predictor=JPB 那一行 = $a_1$；Outcome=BI, Predictor=JPB = $c'$（直接效果）
  • 不要寫 BI ~ a*JPB——JASP 會把 a 當成 0~1 之間的母體真值並跳警告

範例 C — Mediation（中介，H2 + H3 + H5）

JPB → APT → BI 的部分中介模型。

# Measurement
JPB =~ JPB1 + JPB2 + JPB3
APT =~ APT2 + APT3                # 假設 APT1 已因 loading < .40 刪題
ASE =~ ASE1 + ASE2 + ASE3
BI  =~ BI1  + BI2  + BI3

# Structural — 無標籤、無 := 衍生參數
APT ~ JPB + ASE                   # H2: a 路徑；H4: ASE → APT
BI  ~ JPB + APT                   # H5: c'（direct）；H3: b 路徑

JASP 跑完後，從 Regression Coefficients 表手動抄出：

JASP 表格行（Outcome / Predictor） 論文符號 對應假設
APT / JPB $a$ H2
BI / APT $b$ H3
BI / JPB $c'$ H5

到 Excel 算 Sobel 間接效果（z 與 95% CI）：

$$\text{Indirect} = a \times b, \quad SE_{ab} = \sqrt{a^2 \cdot SE_b^2 + b^2 \cdot SE_a^2}$$

$$z = \frac{a \times b}{SE_{ab}}, \quad 95\%\,\text{CI} = (a \times b) \pm 1.96 \times SE_{ab}$$

Bootstrap CI（BCa）優於 Sobel（後者假設常態），但 JASP-only 流程必須用 Sobel；論文需註明此限制。

範例 D — Moderation（調節，H6）— Product Indicator 法

ASE 調節 JPB → APT 的關係。核心關鍵：seminr 不會自動建互動項，必須在 CSV 預先計算好乘積指標再讀進 JASP。

Step 1：在 CSV 預先計算 mean-centered product indicators

對 ASE（3 題）與 JPB（3 題）的所有題目：

  1. 各題減去自身樣本平均：$\text{ASE}_{i,c} = \text{ASE}_i - \overline{\text{ASE}_i}$、$\text{JPB}_{j,c} = \text{JPB}_j - \overline{\text{JPB}_j}$
  2. 兩兩相乘 → 9 個 product indicators：$\text{ASExJPB}_{ij} = \text{ASE}_{i,c} \times \text{JPB}_{j,c}$（命名：ASExJPB_11、ASExJPB_12、… ASExJPB_33）
  3. 存檔，JASP File → Open 重新讀檔

為何要中心化：未中心化會造成互動項與主效果嚴重共線性（實測 inter-block $r$ 可達 .977，APT 方程式 SE 爆 4 倍）。依 Aiken & West (1991) 與 Hair_2022_PLS 必須先中心化。

Step 2：JASP Model syntax
# Measurement + interaction construct
JPB     =~ JPB1 + JPB2 + JPB3
APT     =~ APT2 + APT3
ASE     =~ ASE1 + ASE2 + ASE3
BI      =~ BI1  + BI2  + BI3
ASExJPB =~ ASExJPB_11 + ASExJPB_12 + ASExJPB_13 +
           ASExJPB_21 + ASExJPB_22 + ASExJPB_23 +
           ASExJPB_31 + ASExJPB_32 + ASExJPB_33

# Structural — 互動項以新構念身分加進預測式
APT ~ JPB + ASE + ASExJPB         # H6: 互動項本身的 β = a_3
BI  ~ JPB + APT

⚠️ 不要寫 ASExJPB ~ JPB + ASE——seminr 把互動構念當外生構念，自動允許與 JPB / ASE 相關，再寫會造成 DAG 循環。

  • 看什麼：Outcome=APT, Predictor=ASExJPB 行的 β / SE / p / 95% CI 即 H6 結論
  • f² 解讀：互動項 f² ≥ .025 為小效果、≥ .15 中、≥ .35 大（Hair_2022_PLS）
  • 報告寫法：「以 product indicator approach（Chin 2003、Henseler 2010）構成單一互動構念 ASExJPB（reflective Mode A）」

範例 E — Mediated Moderation（中介式調節）

概念釐清：Mediated moderation 問的是「X 與 W 的互動效果，是否透過 M 影響 Y」——亦即互動項 (X×W) → M → Y。互動發生在前段，中介在後段。

# Measurement（同範例 D，含 ASExJPB 9 個 product indicators）
JPB     =~ JPB1 + JPB2 + JPB3
APT     =~ APT2 + APT3
ASE     =~ ASE1 + ASE2 + ASE3
BI      =~ BI1  + BI2  + BI3
ASExJPB =~ ASExJPB_11 + ASExJPB_12 + ASExJPB_13 +
           ASExJPB_21 + ASExJPB_22 + ASExJPB_23 +
           ASExJPB_31 + ASExJPB_32 + ASExJPB_33

# Structural — 互動項透過 APT 中介到 BI
APT ~ JPB + ASE + ASExJPB         # 互動項影響 M（APT）
BI  ~ APT + JPB                   # M 影響 Y；JPB 直接效果保留以判斷部分 vs 完全中介
  • 抄這三個係數做 Sobel：
  • $a_3$ = Outcome=APT, Predictor=ASExJPB 的 β（互動 → M）
  • $b$ = Outcome=BI, Predictor=APT 的 β（M → Y）
  • Mediated moderation 效果 = $a_3 \times b$
  • 判讀：若 $a_3$ 顯著且 $a_3 \times b$ Sobel CI 不跨 0 → mediated moderation 成立（互動效果是「透過 APT 傳遞」到 BI）
  • 與範例 D 的差別：範例 D 只看互動項對 APT 的直接效果；本範例追蹤該互動效果是否進一步傳到 BI

範例 F — Moderated Mediation（調節中介，H7）

概念釐清：Moderated mediation 問的是「間接效果 a × b 的強度，是否被調節變項 W 改變」。Hayes (2015) 的 Index of Moderated Mediation（IMM）= $a_3 \times b$，其中 $a_3$ 是「W 調節 X→M」的互動係數。

JPB → APT → BI 的中介，被 ASE 調節「JPB → APT」這一段：

# Measurement（同範例 D，含 ASExJPB 9 個 product indicators）
JPB     =~ JPB1 + JPB2 + JPB3
APT     =~ APT2 + APT3
ASE     =~ ASE1 + ASE2 + ASE3
BI      =~ BI1  + BI2  + BI3
ASExJPB =~ ASExJPB_11 + ASExJPB_12 + ASExJPB_13 +
           ASExJPB_21 + ASExJPB_22 + ASExJPB_23 +
           ASExJPB_31 + ASExJPB_32 + ASExJPB_33

# Structural
APT ~ JPB + ASE + ASExJPB         # a 路徑被 ASE 調節
BI  ~ APT + JPB                   # b 路徑與直接效果

語法上 E 與 F 完全相同；差別只在研究問題與 Excel 後處理的解讀方式。E 問「互動效果有沒有被中介」，F 問「中介效果有沒有被調節」——兩者其實是同一個 statistical model 的兩種理論詮釋。

Excel 手算 IMM（Index of Moderated Mediation, Hayes 2015）

從 Regression Coefficients 表抄： - $a_3$（互動 → APT 的 β + SE） - $b$（APT → BI 的 β + SE）

$$\text{IMM} = a_3 \times b$$

$$SE_{\text{IMM}} = \sqrt{a_3^2 \cdot SE_b^2 + b^2 \cdot SE_{a_3}^2}$$

$$z = \text{IMM} / SE_{\text{IMM}}, \quad p = \texttt{=2*(1-NORM.S.DIST(ABS(z),TRUE))}$$

$$95\%\,\text{CI} = \text{IMM} \pm 1.96 \times SE_{\text{IMM}}$$

判讀： - CI 不跨 0 + p < .05 → 調節中介成立（W 顯著改變間接效果強度） - CI 跨 0 → 不支持 H7。常見原因是 $a_3$ 本身就不顯著（IMM 為兩者乘積）

Conditional Indirect Effects（高低 ASE 下的間接效果）

在 ASE 的 +1 SD 與 −1 SD 兩個水準上，分別計算間接效果：

$$\text{Indirect}|_{\text{High ASE}} = (a_1 + a_3 \cdot SD_{\text{ASE}}) \times b$$ $$\text{Indirect}|_{\text{Low ASE}} = (a_1 - a_3 \cdot SD_{\text{ASE}}) \times b$$

報告於論文時，搭配 Johnson-Neyman 區間（若需精準的「W 在哪個值之上 / 之下調節顯著」）。

A 純 CFA × × 無，只看信效度
B 主效果 × × 直接讀 β / CI
C Mediation × ✅ $a \times b$ 與 SE
D Moderation ✅（產品指標） × 互動項 β / f²
E Mediated moderation ✅ ✅ $a_3 \times b$（透過 M 傳遞的互動效果）
