Prompt 分級闖關：五關由淺到深，把原則練成肌肉

跨課程可重用。是「基礎六原則」與「三段式」之間的純練手感關卡：一關練一招，每關都有壞例→好例對照，做完馬上自評。假設學員零基礎。

🎯 目標

把六原則從「聽懂」練到「手會」。五關各鎖定一個 prompt 技能，從最簡單的「改寫爛 prompt」爬到「連續追問把成品磨到能用」。重點不是全部做完，是每關親手打一次、親眼看差別。

⏱️ 課堂帶法（40 分鐘）

1.（3′）說明玩法：一關一招，貼「起手 prompt」送出、再貼「升級 prompt」送出，並排比。 2.（30′）學員自行闖關，助教巡場；卡住看該關的救援。 3.（5′）分享：你在哪一關「看到最大落差」？ 4.（2′）預告：這五招下一頁會被收進「三段式」骨架一次到位。

玩法：每關都在同一個對話裡，先送「起手」版看它給什麼，再送「升級」版，把兩次結果並排。差別越大，代表這一招越有感。

🎮 五道關卡

LV.1改寫爛 prompt技能：具體化

任務：把一句模糊的請求，改成有對象、有限制、有格式的版本。

✗ 起手幫我寫個公告。
✓ 升級幫我寫一則「圖書館本週六因設備維護閉館一天」的公告，貼在大門與官網，語氣簡明、控制在 80 字內。
🆘 還是很空泛？逐一補上：什麼事、給誰看、貼哪、多長四項。
LV.2加限制條件技能：設邊界

任務：同一個請求，用「限制」把 AI 的自由發揮收進你要的範圍——字數、語氣、不准編造。

✗ 起手介紹一下我們新上線的線上申辦系統。
✓ 升級介紹我們新上線的線上申辦系統，給民眾看。限制：不超過 120 字、條列 3 個好處、不要編任何我沒給的功能或數字、結尾附一句「詳情請洽本所」。
🆘 它還是自己亂加功能？在最後補一句「不確定的地方寫〔待補〕，不要自行假設」。
LV.3給範例（few-shot）技能：示範

任務：貼一個「你要的樣子」當範本，要 AI 照著產出同款的下一則。示範一次，勝過形容詞十句。

照下面這則的語氣與格式，再幫我寫兩則不同主題的：

範例：
【活動快訊】親子共讀時光｜7/26（六）10:00｜3F 兒童區
歡迎爸媽帶孩子一起聽故事，免報名，額滿為止。

請比照，幫我寫：(1) 銀髮族數位課程 (2) 二手書交換市集
✗ 沒範例幫我寫三則活動快訊。（→ 格式各異，還要你手動統一）
✓ 有範例（上面那段）→ 三則格式一致，直接能排版。
🆘 產出跟範例不像？把範例裡的「固定結構」明講出來：「每則都要有【標籤】、時間、地點、一句說明」。
LV.4指定輸出格式技能：結構化

任務：要 AI 直接吐出「你不用再重排」的結構——表格、分點、JSON 皆可。

我要籌辦一場社區座談，幫我把待辦拆成一張表格。
欄位：任務、負責角色、期限（用相對天數如 T-7）、備註。
至少 8 列，依時間先後排。只給表格，不要前後多餘說明。
✗ 起手幫我想辦座談要做哪些事。（→ 一大段文字，難追蹤）
✓ 升級（上面那段）→ 一張可直接貼進 Excel 的分工表。
🆘 表格跑版？加「用 Markdown 表格格式輸出」，或請它「改成可貼進 Excel 的 CSV」。
LV.5連續追問磨成品技能：迭代

任務：在同一對話裡跑「產出→追問→再產出」三輪，把一份初稿磨到「明天真的能用」。

示範追問三連（依序貼）：

第一版拿到後：
① 第二段太官腔，改白話，像在跟里民講話。
② 加一句提醒對方「7/30 前回覆」。
③ 幫我準備一個「更正式」和一個「更親切」兩種版本讓我挑。
🎯 迭代的關鍵：一次只改一件事，講清楚「哪裡、怎麼改」。不要一句話塞五個要求，也不要不滿意就整段重寫——AI 記得前文，你只要說差在哪。
🆘 越改越糟、它開始鬼打牆？別在同一對話硬凹，開新對話、把「已經調好的乾淨版本」重貼一次當新起點。

✅ 完成標準

五關至少完成三關，並能講出「哪一關讓我看到最大落差」。做完你會發現：好 prompt 不是靈感，是把六原則逐項補齊的機械動作。

🔀 變體

  • 競賽版：同一起手 prompt，比誰用最少字把結果調到全班公認最好。
  • 版本對照版：把 LV.5 的最終 prompt，在同一平台的「快版」與「強版」各跑一次，比較深度差異（呼應〈同一題問三家 AI〉）。
  • 大學課版：情境全換成校園（社團公告、報告分工表、回教授信）。
