AI 寫作辨識講義（大學生 / 研究生版）

#handout　#ai_writing_literacy　#media_literacy　#llm_detection　#academic_writing　#stylometry

AI 寫作辨識講義（大學生 / 研究生版）

給：大學生、研究生、寫作課修課同學、論文指導教授 主題：辨識學術論文 / 課堂評論中的 LLM 痕跡；避免在自己作業中複製 AI 套語 用法：研究方法課、論文寫作課、學術倫理講座 課時：1.5 小時

為什麼這份講義對你重要

ChatGPT 推出以後，大學作業、期末報告、甚至碩博論文文獻回顧裡的 AI 痕跡越來越多。三個風險疊加：

  1. 被指導教授一眼識破：教授閱讀量大、對「文體感」敏感，AI 寫的學術文章有極穩定的句法指紋
  2. 學術不誠信指控：許多大學現在的學術倫理規範把「未揭露的 AI 生成內容」列為違規
  3. 自我風格污染：你看多了 AI 寫的學術論文，自己寫作會不自覺學起 AI 的句法癖好，永遠寫不出個人聲音

這份講義基於 comparison_llm_patterns 的跨樣本實證——97 篇真實自由時報社論 + 364 篇真實聯合報社論 + 14 篇 Claude 生成繁中評論——萃取出 12 條可量化的 LLM 句法 pattern，並給每條配 baseline 對照數據。

第一講｜LLM 句法 fingerprint 的計量基礎

1.1 為什麼可以量化

語言生成模型（Claude / GPT-4 / Gemini）的訓練過程偏好統計上「安全」的 token 序列：高概率連接詞、平衡對偶結構、抽象名詞化短語。這在 comparison_llm_patterns 與 llm_chinese_writing_tics §3.6 已有跨樣本實證——LLM 在 12 個結構性 pattern 上的密度與人類寫作有顯著差異（多數為 4-40 倍）。

最重要的方法論基礎：這些 pattern 用簡單 regex 即可偵測，不需要黑盒 AI 分類器。可解釋、可複製、可教學。

1.2 風格指紋的三大徵候群

徵候群 機制 代表 pattern
對偶癖 RLHF 訓練偏好「平衡」「對比」結構 + essay 訓練語料含大量 "not A but B" 翻譯句 P01 二元對偶、P03 二元對立框架、P10 破折號
抽象名詞化癖 LLM 偏好「N 的 N」結構降低 perplexity P04 抽象套語、P06 政治哲學辭藻、P12「所反映的 X」
過渡套語癖 Essay-writing 訓練讓 LLM 段落間自動加 transition P05「值得追問 / 換言之」、P08「從來不是 / 並不只是」

詳見 llm_chinese_writing_tics §1。

第三講｜真實例句的句法解剖

以下例句全部來自本講義 corpus 經 audit 篩選的 LLM 生成樣本。每個例句解剖其句法結構，說明為什麼這樣寫等於暴露 LLM 痕跡。

例句 1（P10c × P11 × P04 × P03 同時觸發）

來源：02_disinfo_b.md（topic: 假訊息） 「這套被個體化、被微觀化、被去脈絡化的研究取徑，本身就是當代假訊息研究最深的破口。」

句法解剖： - 被 X、被 Y、被 Z 化：三段並列被動結構（P11 變體） - 本身就是：是抽象主語回扣的套語 - 最深的破口：政治哲學辭藻 + 隱喻名詞化 - 整句沒有具體行為主體，只有抽象標籤的堆疊

人類學者會寫成：「這種研究取徑把假訊息問題化約到個體心理層次，把它從歷史脈絡與政治經濟結構中抽離，這是當前文獻最大的盲點。」（主動句、有行為對象、避免「化—被—的」鏈）

例句 2（P10b 雙 em-dash 補語式）

來源：01_disinfo_a.md 「當代假訊息生態的核心特徵——並非單一行動者的惡意，而是平台演算法、付費廣告系統、外國干預、商業內容農場、政黨側翼帳號、自願轉傳的一般公民六方共同建構的——治理品質低落、制度設計失能、結構性監管真空的多層次失序狀態。」

句法解剖： - 兩對 ——（觸發 P10b ×2 + P10c ×4 個字元） - 中間夾入「並非 X，而是 Y」（P01） - 結尾「治理品質／制度設計／結構性」三連發（P06） - 六項並列（P11） - 整句 99 字，沒有句點切分

人類學者會寫成：「假訊息生態並非單一行動者造成的。它包含演算法推薦、廣告系統、外國干預、內容農場、政黨側翼、與一般公民的轉傳行為。這六方共同建構了一個多層次失序狀態。」（三句分開，破折號改成句點，「治理品質／結構性」這類名詞化標籤刪除）

例句 3（P08 否定強化開頭 × P12 「所暴露的」）

來源：05_election_a.md（topic: 2024 大選後媒體環境） 「Facebook、YouTube、TikTok、Instagram、Threads 五個平台所暴露的並不只是訊息傳播管道的多元化，更是——演算法邏輯、付費廣告、KOL 政治影響力、平台政策差異四方共構的根本性權力重組。」

句法解剖： - 所暴露的（P12） - 並不只是 X，更是 Y（P08 + 變體 P02） - —— 接四項並列（P11） - 結尾「根本性權力重組」名詞化

人類學者會寫成：「五個平台不僅讓訊息傳播管道更多元，也重新分配了演算法、廣告、KOL、平台政策之間的權力關係。」（主動敘述，避免「所 V 的」結構，破折號刪掉）

第四講｜論文寫作的自我審查工具

4.1 五步驟人工檢查

寫完任何論文段落，跑過以下檢查：

Step 檢查項目 警戒值（per 1000 字）
1 數「——」em-dash 字元數量 ≤ 1（baseline）／> 3 即可疑
2 數「不是 X，而是 Y」對偶句 ≤ 1（baseline 0.25）／> 2 即可疑
3 數「從來不是 / 並不只是」開頭 ≤ 0.5（baseline 0.01）／> 1 即可疑
4 數「結構性 / 系統性 / 根本性 / 制度設計」 ≤ 1（baseline 0.03）／> 2 即可疑
5 數「所反映 / 所暴露 / 所揭示的 X」 baseline = 0／> 0 即可疑

4.2 Regex 自動審查腳本

可重用工具：analyzer_llm_patterns.py

import re
PATTERNS = {
    "P01": re.compile(r"(?:不是|並非|並不是|從來不是)[^。！？\n]{1,30}?[，、][^。！？\n]{0,15}?而是"),
    "P06": re.compile(r"(?:治理品質|民主韌性|制度設計|系統性|政治話術|結構性|根本性|象徵性|實質性)"),
    "P08": re.compile(r"(?:從來不(?:是|只)|並不(?:只|僅)是|遠不止|不僅僅是|絕不只是|早已不是)"),
    "P10c": re.compile(r"—"),
    "P11": re.compile(r"[一-鿿]{2,6}、[一-鿿]{2,6}、[一-鿿]{2,6}(?:、[一-鿿]{2,6})?(?:等)"),
    "P12": re.compile(r"所(?:反映|暴露|揭示|呈現|凸顯|折射|印證)(?:的|出的)"),
}

text = open("my_paper.md", encoding="utf-8").read()
chars = len(text)
print(f"Total chars: {chars}")
for pid, regex in PATTERNS.items():
    hits = len(regex.findall(text))
    print(f"{pid}: {hits} hits, {hits*1000/chars:.2f}/1k")

4.3 文獻回顧的特殊風險

寫文獻回顧時 LLM 痕跡最容易暴露——因為：

  1. 過度抽象化：LLM 寫文獻回顧愛用「典範轉移／結構性挑戰／根本性危機」這種高度抽象的概念詞，但這些詞在原始文獻裡可能根本不存在
  2. 虛構引用：LLM 會生成「看起來合理但不存在」的論文（Author, Year, Title）。每個引用都要實際查證
  3. 七段論結構：問題 → 現象 → 歷史 → 比較 → 分析 → 價值 → 呼籲——這套骨架太工整，反而像 AI

建議流程：先用 LLM 整理你看過的論文摘要 → 自己重寫文獻段落 → 跑 regex 檢查 → 人工潤飾

第五講｜兩處批判反思

5.1 批判反思 1：regex 偵測的限制

本講義所提的 12 條 pattern 用 regex 偵測，有三個結構性限制：

  1. 誤判：人類也會用「不是 X，而是 Y」對偶（baseline 0.25/1k 不是 0）。單一 pattern 命中不足以判定 AI，必須看整體 fingerprint
  2. 逃避偵測：LLM 知道有 detector 後，可以被 prompt 訓練降低這些 pattern 密度（已有研究證實，見 Adversarial prompts of sufficient length can trigger any behavior present in LLM training distribution）
  3. 跨模型差異：本講義 baseline 對照只用 Claude Opus 4.7。GPT-4 / Gemini 的 fingerprint 可能不同

討論問題：如果一個學生用 Claude 寫初稿，然後手動修改去掉所有「——」「不是…而是」「結構性」——這還算 AI 寫作嗎？學術倫理該如何界定？

5.2 批判反思 2：baseline 對照的代表性

本講義 baseline 用「自由時報 + 聯合報 2025-2026 社論」。這個 baseline 有兩個限制：

  1. 文體偏差：社論是高度規範化的評論文體，與學術論文、散文、報告體裁不同。學術論文的 baseline 應該換成期刊論文 corpus
  2. 時代偏差：2025-2026 社論本身可能已被 LLM 影響（記者用 AI 輔助寫作越來越普遍），baseline 本身可能不夠「純」

討論問題：建立一個「純人類寫作」的 baseline 是否可能？1990 年代以前的中文評論 corpus 是否更適合當基準？

6.3 ⚠️ LLM 不可信任的地方（必須交叉驗證）

使用 LLM 輔助學術寫作時，這些地方務必人工複查：

  1. 虛構參考文獻：LLM 會編造「看起來合理但不存在」的論文。Web of Science / Scopus / 期刊官網逐筆查
  2. 誤算統計值：LLM 會口算 effect size / R² 並寫得很有自信，但常常算錯
  3. 過時的方法論標準：LLM 給的方法論 cutoff（如 Cronbach α ≥ .7）可能來自過時版本
  4. 編造作者立場：LLM 會寫「Habermas 認為 X」但實際上原作裡沒有這句話
  5. 混淆學派立場：LLM 經常把「批判理論」「結構功能論」「制度論」的立場混為一談
  6. 過度平衡敘述：LLM 訓練偏好「兩邊都有道理」的中庸式論述，可能掩蓋你真實的論證立場

結語

LLM 不是論文寫作的敵人——是放大鏡。它會放大你寫作習慣的優點，也會放大缺點。正確的使用方式：先自己寫，再用 LLM 提建議，最後用 regex 檢查 LLM 痕跡有沒有殘留。

第七講｜建立 domain-specific baseline 的方法論

7.1 為什麼社論 baseline 不夠用

本講義 baseline 主要依 corpus_ltn_editorial_2026（97 篇）+ corpus_udn_editorial_2025_2026（364 篇）兩報社論建立，但社論 baseline 不能直接套用到學術論文審查。理由：

  1. 文體張力不同：社論強調情緒動員與短時效的議題切割；學術論文強調概念精確與長時效的論證鋪陳，本身就會出現較多抽象名詞化與對偶結構
  2. 句長分布不同：社論 mean 句長 25-30 字、學術論文 mean 句長 35-50 字。同樣的 pattern 密度在學術文體裡相對「自然」的容忍度更高
  3. 論證結構不同：學術論文有「文獻 → gap → 假設 → 方法 → 發現」的固定骨架，本身就需要過渡語（P05），baseline 應該對應較高

但 §2 corpus 實測仍顯示 LLM 學術寫作的 P10c em-dash 是 LTN baseline 的 3000 倍——這意味著即使學術 baseline 高出社論 baseline 2-3 倍，LLM 偏離仍極端顯著。

7.2 建立 domain-specific baseline 的最小可行流程

若您的學科有特定學術寫作風格（如管理學量化論文、社會學質性論文、傳播學批判論文），建議自建 baseline。流程依 corpus_analysis_guide：

  1. 採樣 30-50 篇：選擇 2010-2020 年之間（避免 ChatGPT 後 LLM 滲透）、目標期刊已發表、第一作者為母語繁中學者的論文
  2. 抽取「Discussion」段落：學術論文的 Discussion 是 LLM 最常滲透的段落（因為它需要 abstract reasoning），baseline 應該對應 Discussion 風格
  3. 跑相同 regex：用 §4.2 腳本算每 1000 字命中數，建立每個 pattern 的 mean ± 1 SD 警戒線
  4. 警戒值校準：可疑論文 = 任一 pattern > baseline mean + 2 SD（95% 信賴區間外）
  5. 跨期刊驗證：同 pattern 在不同期刊密度應相近，差距 > 50% 表示樣本不均衡需補

7.3 1990 年代以前 corpus 的價值

2025-2026 社論本身可能已被 LLM 影響（記者 AI 輔助寫作越來越普遍），baseline 本身不夠「純」。建議補充：

  • 聯合報 / 中國時報 1985-1995 社論（紙本電子化）作為「純人類」baseline
  • 學報級期刊 1990-2010（《新聞學研究》《傳播與社會》等）作為「純人類學術」baseline
  • 兩者跨時期對照可量化 2020 年後 LLM 對人類寫作風格的滲透程度
