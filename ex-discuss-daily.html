小組討論：AI 在日常公務怎麼用得最順？

這是一場Best Practice 交流：每個人手上都有一些「AI 在日常工作幫上大忙」的小撇步，把它們攤開來、選一個最有共鳴的場景，一起打磨出一段「大家都能拿去用」的最佳 prompt，最後上台分享。

✨ Take aways（你會帶走什麼）

你會帶走一批同事實測過的日常公務 AI 用法，以及一段你們組共同打磨、可以直接複製回單位用的最佳 prompt 範本。別人踩過的坑你不用再踩。

💬 討論題（依序聊，邊聊邊記）

暖身（每人一句）：講一件你最近用 AI 幫上忙的小事——寫了什麼、省了多少時間？
  1. 盤點日常場景：組內把「每週都要做、又適合交給 AI」的重複工作列出來（發通知、回罐頭信、寫會議紀錄、擬公告、整理民眾意見、翻白話…）。
  2. 選一個共通場景：挑一個大家都會碰到的（例如「擬一則內部通知」或「回覆民眾詢問」），當作這組要深入打磨的題目。
  3. 交換各自的招：針對這個場景，每個人講自己怎麼下 prompt、加了什麼讓結果更好、怎麼追問微調。
  4. 整合成一段最佳 prompt：把大家的好招合起來，寫出一段「照著填空就能用」的 prompt 範本。
  5. 提醒與紅線：這個場景有沒有個資／機密要注意？（呼應 去識別化）

📝 小組學單（邊討論邊填）

🗒️ 我們這組挑的場景
  1. 我們深入打磨的場景是：
  2. 這件事以前手動大概要花：（分鐘）
  3. 讓結果變好的三個關鍵（背景／角色／限制／範例／格式，挑三個）：
    、、
  4. 一個要小心的地方（個資／機密／容易亂編）：

🎯 每組要交：一段「最佳 prompt 範本」

把你們組打磨出來的 prompt 寫成可以照填的骨架，用〔〕標出要換的地方。參考格式：
【背景】我是〔單位／角色〕，要處理〔什麼事〕，對象是〔誰〕。
【任務】請幫我〔做什麼〕，必須包含〔要件1〕〔要件2〕。
【格式】語氣〔正式／親切〕，長度〔X 字內〕。
【不要】不要編〔日期／數字〕，不確定的寫〔待補〕。
這份範本就是你們組的成果——填得越具體，別人拿去越好用。

🎤 上台報告（每組 2 分鐘，講三件事）

📢 報告三重點
  1. 我們挑的場景＋為什麼：哪件日常工作、多少人天天在做。
  2. 我們的最佳 prompt：唸出範本，特別點出「加了哪一味讓結果變好」。
  3. 一個提醒：這個場景要注意的坑或紅線。

📌 完成標準

組內每人都分享到自己的用法、選定一個共通場景、產出一段「照填就能用」的最佳 prompt 範本並完成報告。

🔀 延伸練習／自我加強

  • 把別組報告的最佳 prompt 也抄下來，回單位挑一個實際套用一週。
  • 把你們組的範本存成單位共用檔（LINE 記事本／共享文件），讓同事都能填。
  • 想再進階，帶著這個範本去做 做成可重用模板 練習，或直接做成 專屬助手。
