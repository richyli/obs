PLS_MGA

PLS_MGA 比較結構路徑在不同群組（如資深 vs 資淺）間是否有顯著差異。

主要方法： 1. Henseler_PLS_MGA（permutation 法，預設） 2. parametric_MGA（t-test 法） 3. Welch_Satterthwaite（變異不等時）

前置：須先通過 MICOM 至少 metric invariance。 判讀：$p_{MGA} < .05$ 表路徑在兩組間有顯著差異。

方法說明

目的

  • 主要研究目的：檢驗 PLS-SEM 結構路徑在不同群組（如性別、文化、產業）間是否有統計顯著差異
  • 次要用途：moderation 的離散版本；驗證理論模型的跨群普適性

流程

  1. 先以 MICOM 三階段檢驗測量恆等性，至少需通過 metric invariance（Henseler_2016_MICOM）
  2. 將樣本依群組變項分組
  3. 對每群分別跑 PLS-SEM，取得 path coefficient 與 bootstrap standard error
  4. 選擇比較法：permutation（Henseler_PLS_MGA）或 t-test（parametric_MGA）；變異不等時用 Welch_Satterthwaite
  5. 對每條結構路徑計算 $p_{MGA}$
  6. 報告通過顯著的路徑差異與其方向

適用範圍

  • 適用：兩群或多群比較、moderation 為類別變項時
  • 不適用：MICOM 未通過 configural invariance（測量結構不同，無法比較係數）
  • 樣本規模建議：每群 N ≥ 100；MGA 推薦每群 ≥ 200
  • 資料類型要求：通過 MICOM 的兩個以上群組
