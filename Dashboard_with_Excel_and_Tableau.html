Tableau Dashboard 基礎教案

#tableau　#dashboard　#teaching　#data_visualization　#NCCU_Teach

Tableau Dashboard

https://bit.ly/r-tableau

操作項目清單（逐項進行）

每完成一項打勾。括號內為建議時間，合計約 60 分鐘。

基礎環境

  • [ ] ① 連結 CSV 資料（2 min）— File → Connect → Text File
  • [ ] ② 確認欄位型別（2 min）— 日期 / 數值 / 字串型別辨識
  • [ ] ③ 建立 Hierarchy（3 min）— Category + Sub_Category → Product 層級

圖表建立

  • [ ] ④ 長條圖（8 min）— Columns / Rows 拖曳、Color encoding、排序
  • [ ] ⑤ Hierarchy drill-down（2 min）— 點 + 展開子品類
  • [ ] ⑥ 折線圖（8 min）— 日期層級切換（年→月）、多條折線
  • [ ] ⑦ Reference Line（2 min）— 加入平均值參考線
  • [ ] ⑧ 地圖（Map）（8 min）— 雙擊 Country、Filled Map、Color by Sales
  • [ ] ⑨ Tooltip 自訂（2 min）— 加入 Profit 至 Tooltip
  • [ ] ⑩ Small Multiples（8 min）— Category 放 Rows、Month 放 Columns、Trellis 排版
  • [ ] ⑪ Sankey Chart（10 min）— Continent → Category → Sub_Category 銷售流向（Extension 或原生）

Dashboard 組合

  • [ ] ⑫ 建立 Dashboard（5 min）— 拖入 5 個 Sheet、Container 排版
  • [ ] ⑬ 加入篩選動作（5 min）— Dashboard Actions → Filter（點擊地圖篩選）
  • [ ] ⑭ 全域篩選器（2 min）— Category Filter 套用到所有 Sheet
  • [ ] ⑮ 匯出 / 分享（2 min）— Export as Packaged Workbook (.twbx)

學習目標

完成本課後，學員能夠： - 連結 CSV 資料並確認欄位型別 - 建立長條圖、折線圖、地圖、Small Multiples、Sankey 五種圖表 - 將圖表組合成互動式 Dashboard 並加入篩選動作

資料集：retail_monthly.csv

虛擬全球零售月報，7,200 筆（10 國 × 6 子品類 × 120 個月）

欄位 型別 說明
Date Date 每月第一天，格式 YYYY-MM-DD（2015-01 ~ 2024-12）
Country String 10 個國家，涵蓋五大洲（見下表）
Category String 第一層品類：Electronics / Clothing / Furniture
Sub_Category String 第二層子品類（見下表）
Sales Integer 當月銷售額（USD）
Profit Integer 當月利潤（USD）
Quantity Integer 當月銷售數量（件）

國家分布（供地圖練習）：

洲別 國家
北美 United States、Canada
南美 Brazil
歐洲 United Kingdom、Germany、France
亞洲 Japan、China、India
非洲 South Africa

品類二層結構（供 Hierarchy 練習）：

Category（第一層） Sub_Category（第二層）
Electronics Phones、Computers
Clothing Apparel、Accessories
Furniture Home、Office

資料設計邏輯（講師可分享給學員）： - 每年成長率約 3% - 季節性高峰：11 月（+30%）、12 月（+50%）→ 適合觀察零售旺季 - 利潤率：Electronics 12% / Clothing 25% / Furniture 20%

課程流程

Part 0｜開場展示（2 分鐘）

先展示最終成品，讓學員有明確目標，再逐步拆解。

展示完成的 Dashboard：地圖 + 折線圖 + 長條圖 + Small Multiples，點擊地圖可篩選其他圖表。

Part 1｜連結資料（5 分鐘）

  1. File → Connect → Text File → 選取 retail_monthly.csv
  2. 確認資料預覽（Data Source 頁籤）
  3. 確認欄位型別：
  4. Date → 日期型（應顯示日曆圖示）
  5. Sales / Profit / Quantity → 數值型（綠色）
  6. Country / Category → 字串型（藍色）
  7. 點 Sheet 1 進入工作表

關鍵概念：左側 Data 面板的藍色（Dimensions）vs. 綠色（Measures）

建立 Hierarchy（3 分鐘，含在 Part 1 內）： 1. 在 Data 面板找到 Category 2. 按住 Ctrl 同時點選 Sub_Category 3. 右鍵 → Hierarchy → Create Hierarchy → 命名為 Product 4. 把 Sub_Category 拖到 Category 下方（確認縮排順序） 5. 之後在圖表中點擊 + / - 符號可展開/收合子品類

Part 2｜長條圖：各國銷售比較（10 分鐘）

目標：比較 5 個國家、3 個品類的銷售額

步驟： 1. 將 Country 拖到 Columns 2. 將 Sales 拖到 Rows（自動加總為 SUM） 3. 將 Category 拖到 Marks → Color → 看到 3 色堆疊 4. 切換為並排長條圖：上方工具列選 Side-by-side Bars 5. 展開 Hierarchy：將 Color 改為 Sub_Category，觀察 6 個子品類的差異 6. 排序：點欄位標頭的排序箭頭，按總銷售額降序 7. 重新命名此 Sheet 為 Bar - Sales by Country

提問：哪個國家的 Electronics 銷售最高？Phones 和 Computers 哪個佔比更大？

Part 3｜折線圖：10 年銷售走勢（10 分鐘）

目標：觀察銷售趨勢與季節性規律

步驟： 1. 新增 Sheet 2. 將 Date 拖到 Columns - Tableau 預設為年份；點欄位右側箭頭 → 選 Month（連續） → 顯示月份走勢 3. 將 Sales 拖到 Rows 4. 將 Country 拖到 Marks → Color 5. 觀察：每年 11-12 月明顯高峰 6. 加入 Reference Line：右鍵 Y 軸 → Add Reference Line → 選 Average（全域平均線） 7. 重新命名為 Line - Monthly Trend

關鍵概念：連續（green pill）vs. 離散（blue pill）日期的差異；點右鍵可切換

Part 4｜地圖：各國銷售地理分布（10 分鐘）

目標：建立 Choropleth（填色地圖）

步驟： 1. 新增 Sheet 2. 雙擊 Country → Tableau 自動辨識地理角色，生成地圖底圖 3. 將 SUM(Sales) 拖到 Marks → Color → 地圖變為填色地圖 4. 點 Color → Edit Colors → 選 Red-Green Diverging 或 Blue-Teal 5. 將 SUM(Profit) 拖到 Marks → Tooltip → 游標懸停顯示利潤 6. 調整地圖背景：上方選單 Map → Map Layers → 試驗不同底圖風格

若 Country 沒有被辨識：右鍵欄位 → Geographic Role → Country/Region

  1. 重新命名為 Map - Sales by Country

提問：哪個國家在地圖上看起來最小但銷售不低？（英國）

Part 5｜Small Multiples：各品類月度趨勢（10 分鐘）

目標：用 Trellis 排版同時比較多個分組，一眼看出品類差異

步驟： 1. 新增 Sheet 2. 將 MONTH(Date) 拖到 Columns（選離散 Month → 顯示 1~12） 3. 將 SUM(Sales) 拖到 Rows 4. 將 Category 再次拖到 Rows（放在 SUM(Sales) 的左邊） → 自動產生 3 個並排的折線圖面板 5. 將 YEAR(Date) 拖到 Marks → Color（顯示各年份顏色差異） 6. 上方工具列選 Fit Width

效果：三個品類各自一行，X 軸對齊，可直接比較季節性差異是否一致

  1. 重新命名為 Small Multiples - Category

進階：把 YEAR(Date) 也加入 Columns，就能看到年度 × 月份的矩陣格局

Part 5.5｜Sankey Chart：銷售流向圖（10 分鐘）

目標：視覺化「銷售額從哪個洲、流向哪個品類、再流向哪個子品類」

Sankey 適合的問題：
- 哪個洲的消費集中在哪些品類？
- Electronics 裡 Phones 與 Computers 各佔多少？
- 流量最大的「路徑」是什麼？

Tableau 建立 Sankey 的兩種方式：

方式 A：Extension（推薦，適合課堂）
  1. 上方選單 Help → Extension Gallery，或至 [https://extensionsgallery.tableau.com](https://extensionsgallery.tableau.com) 搜尋 Sankey
  2. 下載 .trex 檔案（如 SankeyMaker）
  3. 新增 Dashboard → 左側 Objects → Extension → 拖入畫面 → 載入 .trex
  4. 在 Extension 設定中指定：
  5. Source（來源節點）：Continent
  6. Target（目標節點）：Category
  7. Value（流量大小）：SUM(Sales)
  8. 可再加一層：Source → Category，Target → Sub_Category
方式 B：原生 Tableau（進階，需 Table Calculation）

適合已熟悉 Tableau 的學員，課堂可示範概念即可。

核心邏輯：用兩個資料列（起點 / 終點）搭配 WINDOW_SUM 與 INDEX 計算出每條流線的座標，再用 Line Mark 連接。

  1. 準備「長格式」資料：每筆流線需要兩筆記錄（path = 0 和 path = 1）
  2. 建立計算欄位：
  3. X軸 = IF path = 0 THEN 1 ELSE 2 END（或多層時為 1, 2, 3）
  4. Y軸 = WINDOW_SUM(SUM([Sales])) 搭配排序
  5. Mark 設定為 Line，Detail 放 Continent + Category
  6. 用 SIZE() 或 Dual Axis 控制線條粗細

本資料集建議 Sankey 結構：

Continent  ──→  Category  ──→  Sub_Category
Asia              Electronics       Phones
                                    Computers
              Clothing          Apparel
                                    Accessories
              Furniture         Home
                                    Office
Europe        ...
North America ...
South America ...
Africa        ...

重新命名：Sankey - Sales Flow

提問：Asia 的銷售主要流向哪個品類？South Africa 的流量相比其他洲差異有多大？

Part 6｜Dashboard 組合（10 分鐘）

目標：整合 4 個圖表，加入互動篩選

步驟： 1. 底部 Tab 點 ⊕ New Dashboard 2. 左側 Sheets 面板依序拖入： - 上排左：Map - Sales by Country - 上排右：Line - Monthly Trend - 下排左：Bar - Sales by Country - 下排右：Small Multiples - Category 3. 加入篩選器： - 點選 Bar Chart → 右上角出現選單 → 點 Use as Filter 圖示（漏斗符號） - 或：Dashboard → Actions → Add Action → Filter - Source: Map → Target: 所有 Sheets → On Select: Filter 4. 加入 Category 全域篩選： - 點任一含 Category 的 Sheet → 右上角 → 篩選圖示 → 選 Apply to All Sheets 5. 加 Dashboard 標題：Dashboard → Show Title → 輸入「Global Retail Dashboard 2015-2024」 6. 測試：點擊地圖上的國家 → 觀察其他圖表是否同步篩選

版面調整技巧：拖住 Sheet 邊框可調整大小；Container 可使用 Horizontal / Vertical 巢狀排列

Part 7｜互動 Demo 與 Q&A（3 分鐘）

示範： - Highlight Action：Dashboard → Actions → Add Action → Highlight（滑過地圖高亮其他圖表） - 匯出：File → Export Packaged Workbook (.twbx) → 包含資料，可直接給他人開啟

常見問題： - Q：地圖只顯示部分國家？→ 右鍵 Country 欄位 → Geographic Role → Country/Region - Q：日期沒辦法切換到月份？→ 確認 Date 欄位是 Date 型別（非 String） - Q：Small Multiples 面板太多？→ 減少 Rows/Columns 上的維度數量

Dashboard 設計思維：四種角色視角

核心概念：相同資料，不同問題，不同版型。Dashboard 的設計從「這個人每天要回答什麼問題？」出發。

Role 1｜Company CEO — 全局健康儀表板

核心問題：整體業務是否健康？成長動能在哪裡？

設計原則：掃描式閱讀、KPI 先行、不超過 4 個圖表

指標 圖表 說明
總銷售額、利潤、利潤率、YoY 成長 KPI 數字卡片 進門第一眼
各國銷售分布 世界地圖（填色） 哪個市場最大
10 年年度趨勢 折線圖（年彙總） 是否持續成長
品類利潤佔比 長條圖或 Treemap 哪個品類最值錢

Role 4｜Category Manager — 品類深度分析儀表板

核心問題：我的品類在哪個市場最強？哪個子品類的毛利最好值得投資？

設計原則：品類篩選鎖定、子品類下鑽、利潤率意識

指標 圖表 說明
品類銷售、利潤率、最佳市場 KPI 數字卡片 品類大局觀
子品類趨勢 Small Multiples（Phones / Computers） 兩個子品類消長
銷售 × 利潤率散佈圖 Scatter（每點 = 一個國家） 找高價值市場
品類地圖 填色地圖（篩選至本品類） 哪個區域潛力最大

附錄：可供練習的問題

  1. 哪個品類的年均利潤率最高？ → 建立計算欄位 [Profit]/[Sales]，長條圖呈現
  2. 2020 年（疫情）各國銷售是否下滑？ → 折線圖加 Year 篩選器觀察
  3. 哪個月份是全球零售旺季？ → 按月份分組的長條圖（Discrete Month）
  4. 各國銷售成長率比較 → 用 Table Calculation → Percent Difference
