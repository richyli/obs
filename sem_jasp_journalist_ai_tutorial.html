sem_jasp_journalist_ai_tutorial（SEM 入門教學講義｜以政治記者 AI 使用意願資料為例）

工具：JASP（內建 SEM 模組，底層為 R 的 Lavaan） 資料：N ≈ 95 位台灣政治記者問卷（political_journalist_ai_survey_2026） 對象：傳播 / 新聞所碩士班、初次接觸 structural_equation_modeling 的學生

第 1 講｜為什麼不只是「跑迴歸」？

把問卷裡 3 題「使用意願」加總當依變項、用 OLS 迴歸跑，會踩三個雷：

  1. 忽略測量誤差：每一題 Likert_scale 都不是「完美」測到構念，迴歸假設依變項無誤差。
  2. 無法區分「題目」與「構念」：研究的是「使用意願」這個潛在構念，不是 BI1 這題本身。
  3. 多依變項要跑很多次：「risk_perception → 使用意願」「professional_norms → risk_perception → 使用意願」這種中介路徑迴歸要分兩次估計，係數彼此不一致。

structural_equation_modeling 一次解決：測量模型（題目 ↔ 構念）+ 結構模型（構念 ↔ 構念）同時估計。

第 2 講｜把問卷對應成潛在構念

從這份問卷可以萃取四個潛在變項（每個構念 ≥ 3 題才能識別）：

構念 對應題目（建議重新命名） 理論意涵
使用意願 BI BI1 我願意使用 / BI2 工作變動下會考慮 / BI3 整體高度意願 TAM 的 Behavioral Intention
風險認知 RP RP1 錯誤資訊 / RP2 偏見框架 / RP3 媒體公信力 perceived_risk
AI 自我效能 SE SE1 寫清楚提示 / SE2 追問改寫 / SE3 查核修正 ai_literacy / self_efficacy
專業規範 PN PN1 事實查核召喚 / PN2 截稿仍要平衡 / PN3 記者承擔倫理責任 professional_norms

「工作規劃習慣」三題（Q10, Q15, Q21）這次當作可選的控制變項或不放入。

第 3 講｜畫出假設模型

        PN ──(+)──▶ RP
         │            │
         │            │ (−)
         ▼            ▼
        BI ◀──(+)─── SE
  • H1: SE → BI ($+$)　越能駕馭 AI，越想用
  • H2: RP → BI ($-$)　風險感受越強，越不想用
  • H3: PN → RP ($+$)　專業規範越強，越警覺 AI 風險（中介）
  • H4: PN → BI（直接效果，待檢驗）

中介效果 PN → RP → BI 是這個模型最有趣的部分。

第 4 講｜進 JASP 之前的資料整理

CSV 的中文欄名 JASP 會吃，但 Lavaan 語法不友善，先在 Excel / Python 把欄名改短：

原欄名（中文） 新欄名
在政治新聞工作中，我願意使用… BI1
若工作有變動，我會考慮… BI2
整體而言，我對…感到高度意願 BI3
若生成式 AI 產生錯誤資訊… RP1
生成式 AI 放大偏見或不當框架… RP2
生成式 AI 介入後…公信力… RP3
我能把含糊的需求轉換成清楚的提示 SE1
我能透過追問、要求補充或改寫… SE2
我能對 AI 輸出進行必要查核與修正… SE3
政治記者以日復一日驗證事實… PN1
即使在截稿壓力下…平衡與多元… PN2
即使使用新工具…倫理與社會責任 PN3

存成新的 journalist_ai_clean.csv，UTF-8 with BOM。

學生操作步驟（資料前處理）

Step 1｜在 Excel 中重命名欄位 1. 開啟 Google 表單下載的原始 CSV 2. 在第 1 列把 12 個構念題目欄名改成 BI1, BI2, BI3, RP1, RP2, RP3, SE1, SE2, SE3, PN1, PN2, PN3 3. 多餘欄位（時戳、email、自由填答）保留但不會用到

Step 2｜檢查資料品質 - 在 Excel 用 =COUNTA(A:A) 確認每欄樣本數一致（應該都是 95） - 條件格式 → 標出超出 1–5 範圍的值（資料登錄錯誤） - 缺失值以空白保留（不要填 0），JASP 會自動辨識

Step 3｜加分組變項（為了第 8.3 講多群組分析） - 加一欄 seniority，公式：=IF(政治年資欄<7,"junior","senior")

Step 4｜另存新檔 1. Excel → 另存新檔 → 檔案類型選「CSV UTF-8（逗號分隔）」 2. 命名為 journalist_ai_clean.csv 3. 存在桌面或專案資料夾，路徑不要有中文（避免 JASP 讀檔出錯）

第 5 講｜JASP 操作 — 先跑 CFA（驗證性因素分析）

目的：確認「題目真的測到該構念」再走結構模型。

學生操作步驟（CFA 從零到完成）

Step 1｜啟動 JASP - 雙擊 JASP icon。若未安裝，到 https://jasp-stats.org/ 下載 v0.19.3 以上版本（免費） - 介面：左上角 ☰ 是主選單，上方是分析模組 ribbon

Step 2｜載入資料 1. 點左上角 ☰ → Open → Computer → Browse 2. 選 journalist_ai_clean.csv 3. 右側資料窗會顯示變項，左側是分析設定區（一開始空白）

Step 3｜檢查並修正變項類型 - 每個變項欄名左邊有圖示： - 橘色斜線 = Scale（連續） - 黃色長條 = Ordinal - 藍色三球 = Nominal - Likert 5 點本質是 ordinal，但 SEM/CFA 慣例以 Scale 處理 - 若 JASP 自動判定錯誤：點該變項名旁的圖示 → 改成 Scale - 12 個構念題（BI1–PN3）應全部設為 Scale

Step 4｜開啟 CFA 模組 1. 主選單點 Factor（CFA 在 Factor 模組裡，不在 SEM） 2. 下拉選 Confirmatory Factor Analysis 3. 出現左右兩欄設定畫面：左欄是變項清單，右欄是 Factors 設定區

Step 5｜定義 4 個因子 1. 預設只有 Factor 1，點右上 ➕ 新增到 Factor 4 2. Factor 1：點名稱右側鉛筆 icon → 改名 BI → 從左側拖 BI1, BI2, BI3 進來 3. Factor 2：改名 RP → 拖入 RP1, RP2, RP3 4. Factor 3：改名 SE → 拖入 SE1, SE2, SE3 5. Factor 4：改名 PN → 拖入 PN1, PN2, PN3

Step 6｜勾選輸出選項

展開以下面板（黑色三角箭頭點開）：

  • Output options（必勾）
  • ✅ Factor loadings
  • ✅ Standardized
  • ✅ Model fit
  • ✅ Additional fit measures（會列出 AIC, BIC，第 8 講要用）
  • ✅ Modification indices
  • ✅ R-squared
  • ✅ Implied covariance matrix
  • Estimation options
  • Estimator: 預設 ML 即可
  • 若資料嚴重偏態 → 改 MLR（穩健 ML）

Step 7｜執行（JASP 即時跑） - JASP 一勾選就立刻跑，不用按 run - 結果出現在右側結果區 - 重點看三張表：Model fit, Factor loadings, Modification indices

Step 8｜判讀（對照下方判讀表） - 先看 fit indices 是否達標 - 若不達標 → 看 modification indices 找 MI > 10 的項，考慮加 error covariance（如 BI1 ~~ BI2）或刪題

Step 9｜匯出結果 - 結果區任一表 → 右上下拉箭頭 ▼ → Copy 或 Save Image As - 整份匯出：☰ → Export Results → HTML 或 PDF

判讀指標（給學生背的口訣，每個都點進去看詳細定義）：

指標 可接受 良好 在 JASP 哪看
chi_square_df_ratio（$\chi^2/df$） $< 3$ $< 2$ Model fit 表
CFI Comparative Fit Index（Comparative Fit Index） $\geq .90$ $\geq .95$ Model fit 表
TLI Tucker-Lewis Index（Tucker-Lewis Index） $\geq .90$ $\geq .95$ Model fit 表
RMSEA（Root Mean Square Error of Approximation） $\leq .08$ $\leq .06$ Model fit 表
SRMR（Standardized Root Mean Residual） $\leq .08$ $\leq .05$ Model fit 表
Factor Loading（標準化負荷量 $\lambda$） $\geq .50$ $\geq .70$ Factor loadings 表（Std. 欄）
AIC（Akaike Information Criterion） 越小越好 — Additional fit measures
BIC（Bayesian Information Criterion） 越小越好 — Additional fit measures

如果某題 Factor Loading $< .5$，考慮刪題或加 error covariance（看 modification_index，MI > 10 才考慮加）。

第 6 講｜信效度三件套

跑完 CFA 後在報告補上：

指標 標準 公式 / 計算來源
Cronbach alpha（$\alpha$） $\geq .70$ JASP Reliability 模組另跑
CR Composite Reliability（CR） $\geq .70$ $CR = \dfrac{(\sum \lambda_i)^2}{(\sum \lambda_i)^2 + \sum \theta_i}$
average_variance_extracted（AVE） $\geq .50$ $AVE = \dfrac{\sum \lambda_i^2}{n}$
discriminant_validity（區別效度） $\sqrt{AVE} >$ 構念相關 Fornell_Larcker_criterion

學生操作步驟（信效度）

Step 1｜在 JASP 跑 Cronbach α 1. 主選單 → Reliability → Single-Test Reliability Analysis 2. 把 BI1, BI2, BI3 拖入 Variables → 看 Cronbach alpha 值 3. 對 RP, SE, PN 各重複一次（或一次跑四個構念，但分開比較清楚）

Step 2｜手算 CR 與 AVE 1. 從 CFA 結果複製 Standardized factor loadings（$\lambda$）到 Excel 2. 計算 $\theta_i = 1 - \lambda_i^2$（題目誤差變異） 3. 套公式得 CR 與 AVE

Step 3｜畫區別效度表 - 表的對角線填 $\sqrt{AVE}$，下三角填構念間相關（從 CFA 的 Factor covariances 取） - 對角線值應 > 該列、該欄所有非對角值 → 通過 Fornell_Larcker_criterion

JASP 沒有直接給 CR / AVE，需要從 standardized loadings 自己手算或寫個 Excel 表。

第 7 講｜JASP 操作 — 跑完整 SEM

學生操作步驟（SEM 從零到完成）

Step 1｜啟用 SEM 模組（首次使用必做） 1. 點工具列右上角藍色 ➕ icon 2. 在 advanced modules 清單中找 SEM（不是 Factor，那是 CFA）→ 勾選 3. 主選單會多出 SEM 圖示

提醒：JASP 預設不啟用 SEM 模組。CFA 在 Factor 模組裡，但完整 SEM（含結構路徑、中介、模型比較）必須開 SEM 模組。

Step 2｜開啟 SEM 分析 1. 主選單點 SEM → Structural Equation Modeling 2. 出現 Model syntax 語法輸入框（接受 Lavaan 語法）

Step 3｜貼入完整 Lavaan 語法

把以下整段複製貼進 Model syntax 框：

# 測量模型（measurement model）
BI =~ BI1 + BI2 + BI3
RP =~ RP1 + RP2 + RP3
SE =~ SE1 + SE2 + SE3
PN =~ PN1 + PN2 + PN3

# 結構模型（structural model）
BI ~ b1*SE + b2*RP + b3*PN
RP ~ a1*PN

# 中介效果（user-defined parameters）
indirect := a1 * b2
total    := b3 + indirect

Step 4｜勾選輸出選項

  • Output options
  • ✅ Standardized estimates（拿到 $\beta$）
  • ✅ Model fit
  • ✅ Additional fit measures（AIC, BIC）
  • ✅ R-squared
  • ✅ Modification indices（如果 fit 不好用）
  • Estimation options
  • Estimator: ML（樣本 N=95 偏小可考慮 bootstrap 補強）
  • ✅ Bootstrap → 設 1000 ~ 2000 次（中介效果 95% CI 用）

Step 5｜執行與解讀 - 結果區會出現 Regression coefficients 表 → 報告每條路徑的 $\beta$, $p$, 95% CI - Defined parameters 區會列出 indirect 與 total 行，含 bootstrap 95% CI（不能跨 0 才支持中介） - Model fit 表確認結構模型 fit 仍達標（CFI Comparative Fit Index, RMSEA, SRMR） - 看 R-Square 表了解每個內生變項被解釋的變異量

Step 6｜畫路徑圖（選擇性） - JASP 內建 Path diagram 選項（在 Plots 面板） - ✅ Show path diagram → 自動產生標準化路徑係數圖 - 或另存為圖檔 → 用 PowerPoint / draw.io 美化

第 8 講｜模型比較（在 JASP 中操作）

只報告一個模型的適配度是不夠的；好的論文會跟「替代模型」比較，證明你選的這個比較好。JASP 的 SEM 模組（不是 CFA）支援同時跑多個模型並自動產生比較表。

8.1 在 JASP 中加入多個模型

學生操作步驟（多模型分頁）

Step 1｜進入 SEM - 主選單 → SEM → Structural Equation Modeling - 確保已啟用 SEM 模組（見第 7 講 Step 1）

Step 2｜新增模型分頁 1. 預設語法輸入區上方有個 Model 1 分頁 2. 點 Model 1 右側的「+」icon → 出現 Model 2 3. 重複點 + 直到要比較的模型數量都建立好（例如 4 個模型） 4. 每個分頁可獨立輸入 Lavaan 語法，互不干擾

Step 3｜在每個分頁貼不同的 Lavaan 語法 - 點 Model 1 → 貼 baseline 語法 - 點 Model 2 → 貼替代模型語法 - 以此類推

Step 4｜全部勾選必要輸出

切到 Output options（每個 Model 分頁要分別檢查）： - ✅ Model fit - ✅ Additional fit measures（必須勾，否則沒有 AIC / BIC） - ✅ Standardized estimates

Step 5｜檢視自動產生的 Model comparison 表

跑完所有模型後，結果區下方會自動出現 Model comparison 表，包含： - 每個模型的 $\chi^2$, df, AIC, BIC, sample-size adjusted BIC - chi_square_difference_test（$\Delta\chi^2$ 檢定，自動偵測 nested 關係） - $\Delta$AIC, $\Delta$BIC

Step 6｜判斷該用哪個指標 - 若兩模型 nested（一個是另一個的限制版）→ 看 $\Delta\chi^2$ 是否顯著 - 若 non-nested（不同方向、不同結構）→ 看 AIC / BIC（小的勝） - 同時看 $\Delta$CFI Comparative Fit Index 與 $\Delta$RMSEA 補強判斷

8.2 必跑的四種比較

每個比較都列出完整 Lavaan 語法，學生可以直接複製貼到 JASP 的不同 Model 分頁。

(A) 共同方法偏差檢驗 — Harman_single_factor_test
模型 設定
M0：單因子 12 題全部 → 1 個 factor
M1：四因子 BI / RP / SE / PN 各 3 題

M0 語法（貼到 Model 1 分頁）：

GENERAL =~ BI1 + BI2 + BI3 + RP1 + RP2 + RP3 + SE1 + SE2 + SE3 + PN1 + PN2 + PN3

M1 語法（貼到 Model 2 分頁）：

BI =~ BI1 + BI2 + BI3
RP =~ RP1 + RP2 + RP3
SE =~ SE1 + SE2 + SE3
PN =~ PN1 + PN2 + PN3

判讀：M1 的 fit 顯著優於 M0（chi_square_difference_test $\Delta\chi^2$ 顯著、$\Delta$CFI Comparative Fit Index $> .01$、$\Delta$AIC 大幅下降），代表 common_method_bias 不是嚴重問題。

(B) 區別效度比較
模型 設定
M2：四因子完全相關（$\phi = 1$） 兩兩構念相關設為 1
M3：四因子自由相關（baseline） 預設

M2 語法：

BI =~ BI1 + BI2 + BI3
RP =~ RP1 + RP2 + RP3
SE =~ SE1 + SE2 + SE3
PN =~ PN1 + PN2 + PN3

# 強制所有構念相關 = 1
BI ~~ 1*RP
BI ~~ 1*SE
BI ~~ 1*PN
RP ~~ 1*SE
RP ~~ 1*PN
SE ~~ 1*PN

跑 $\Delta\chi^2$。M3 顯著優於 M2 → 構念可分（通過 discriminant_validity）。

(C) 全模型 vs. 完全中介模型（檢驗 H4）
模型 路徑
M4：全模型 PN → BI 直接效果保留、PN → RP → BI 中介
M5：完全中介 PN → BI 限為 0；只剩 PN → RP → BI

M5 語法關鍵行：

BI ~ b1*SE + b2*RP + 0*PN   # 把 PN→BI 限為 0
RP ~ a1*PN

判讀邏輯： - $\Delta\chi^2$ 不顯著（$p > .05$）→ 限制可接受，完全中介（full_mediation）成立，直接路徑可省 - $\Delta\chi^2$ 顯著（$p < .05$）→ 直接路徑必要，部分中介（partial_mediation）

這是檢驗 H3 中介性質的關鍵步驟，論文裡常被審稿人問到。

(D) 反向因果替代模型（理論辯護）
模型 路徑方向
M6：理論模型 SE → BI（會用 AI 才想用）
M7：反向 BI → SE（想用才會學技能）

M7 語法關鍵行：

SE ~ BI + RP + PN   # 反過來，BI 變成預測 SE 的 IV

兩個模型 non-nested，不能用 $\Delta\chi^2$，改看 AIC / BIC 誰小誰勝。BIC 解釋慣例：

  • $\Delta$BIC $> 10$：強證據
  • $\Delta$BIC $6 \sim 10$：明顯
  • $\Delta$BIC $2 \sim 6$：中等
  • $\Delta$BIC $< 2$：差異微弱（理論辯護無力）

8.3 measurement_invariance 測量恆等性（多群組比較）

把樣本依「政治年資 $< 7$ 年 vs. $\geq 7$ 年」切兩組（用第 4 講 Step 3 建好的 seniority 欄），檢驗測量結構在資深 / 資淺記者之間是否相同。

階層 限制 可比較的東西
configural_invariance（M_config） 兩組共用模型結構，參數自由 因子結構是否相同
metric_invariance（M_metric） 加：因子負荷量跨組相等 構念意義是否相同（可比相關）
scalar_invariance（M_scalar） 再加：截距跨組相等 平均數是否可比
strict_invariance（M_strict） 再加：誤差變異跨組相等 嚴格一致性
學生操作步驟（多群組）

Step 1｜在 JASP 載入含 seniority 欄的 CSV - 確認 seniority 是 Nominal 變項（藍色三球圖示）

Step 2｜逐階測試

每階用 Lavaan 的 group 與 group.equal 參數。在 SEM 模組新增 4 個 Model 分頁：

Model 1（configural）：

BI =~ BI1 + BI2 + BI3
RP =~ RP1 + RP2 + RP3
SE =~ SE1 + SE2 + SE3
PN =~ PN1 + PN2 + PN3

在 JASP SEM Options 找 Group variable → 選 seniority

Model 2（metric）：相同語法 + 在 JASP 設定 group.equal = "loadings" （如果 JASP UI 沒有此選項，改在語法用 cfa(model, group="seniority", group.equal="loadings") 調整 R 命令）

Model 3（scalar）：group.equal = c("loadings", "intercepts")

Model 4（strict）：group.equal = c("loadings", "intercepts", "residuals")

Step 3｜判讀（Cheung_Rensvold_2002 慣例） - $\Delta\chi^2$ 不顯著 → 通過該階層 - 但 $\Delta\chi^2$ 對 N 敏感，現代慣例改看： - $\Delta$CFI Comparative Fit Index $< .01$ - $\Delta$RMSEA $< .015$

達到 scalar_invariance 才能比較群組平均數差異；只到 metric_invariance 仍可比群組間結構係數。

8.4 模型比較結果報告範本

為檢驗測量結構，本研究比較四個巢狀模型（表 X）。四因子相關模型（M3）的適配指標（$\chi^2 = 88.4$, df $= 48$, CFI $= .94$, RMSEA $= .067$）顯著優於單因子模型（M0）（$\Delta\chi^2(6) = 142.7, p < .001$；$\Delta\text{AIC} = 130$），亦優於四因子完全相關模型（M2）（$\Delta\chi^2(6) = 47.3, p < .001$），支持構念之間的區別效度，並排除嚴重共同方法偏差。

進一步檢驗中介結構：限制專業規範對使用意願直接路徑為零的完全中介模型（M5）與全模型（M4）相比，$\Delta\chi^2(1) = 1.83, p = .176$，無顯著差異，支持完全中介。專業規範對使用意願的影響完全透過風險認知傳遞。

第 9 講｜怎麼寫進論文

結果寫法範例：

測量模型適配良好（$\chi^2/df = 1.84$, CFI $= .94$, RMSEA $= .067$, SRMR $= .054$），各題標準化負荷量介於 $.61 \sim .89$，皆達顯著（$p < .001$）。各構念 CR 介於 $.78 \sim .88$，AVE 介於 $.54 \sim .71$，符合收斂效度標準。

結構模型顯示，AI 自我效能正向預測使用意願（$\beta = .42, p < .001$），支持 H1；風險認知對使用意願有顯著負向效果（$\beta = -.21, p = .032$），支持 H2。專業規範透過風險認知對使用意願產生間接負向影響（indirect $\beta = -.11, 95\%\,\text{CI}\,[-.21, -.03]$），支持 H3 中介效果。模型比較顯示完全中介模型優於部分中介模型（見第 8 講）。

第 10 講｜這份資料的限制（教學中要強調）

  1. 樣本量 N $\approx 95$ 偏小。SEM 經驗法則 $N > 200$ 或每估計參數 $\geq 10$ 觀察值；這份資料估計參數約 30，理想 $N \geq 300$。可以跑，但要在限制中明寫，並建議 Bayesian_SEM 或 PLS-SEM 做穩健性檢驗。
  2. 共同方法偏差 CMV：所有變項都用同一份自陳問卷收集，容易膨脹相關。可加 Harman_single_factor_test 或 marker_variable_technique。
  3. 橫斷面：不能下因果結論，只能說「結構關係相符」。
  4. 抽樣：政治記者母體小、滾雪球抽樣，外推到其他路線（社會、財經）需保留。
