Welch_Satterthwaite

Welch_Satterthwaite 用於 PLS_MGA 兩組變異不等時的 df 修正：

$$df = \frac{(SE_1^2 + SE_2^2)^2}{\frac{SE_1^4}{n_1-1} + \frac{SE_2^4}{n_2-1}}$$

比 parametric_MGA 的等變異假設穩健，但比 Henseler_PLS_MGA 仍有分布假設。

方法說明

目的

  • 在兩組變異不齊時，為 t 檢定 / PLS_MGA 提供修正的自由度估計（Welch, 1947; Satterthwaite, 1946）
  • 避免假設等變異導致的 Type I error 膨脹

流程

  1. 兩組分別估計參數與 standard error $SE_1, SE_2$
  2. 計算修正後 df：$df = \dfrac{(SE_1^2 + SE_2^2)^2}{\frac{SE_1^4}{n_1-1} + \frac{SE_2^4}{n_2-1}}$
  3. 計算 t 統計量：$t = \dfrac{\hat\beta_1 - \hat\beta_2}{\sqrt{SE_1^2 + SE_2^2}}$
  4. 用修正 df 查 t 分配計算 p 值
  5. 必要時搭配 bootstrap 取代分布假設（即 Henseler_PLS_MGA）

適用範圍

  • 適用：兩組樣本變異不齊、樣本大小不一的均值 / 路徑係數比較
  • 不適用：嚴重偏態 / 重尾分配（改用 Henseler 法或 permutation test）；多組比較需 Bonferroni / Holm 校正
  • 樣本規模建議：兩組各 $\geq 30$ 為佳
  • 資料類型要求：量化資料含 standard error
