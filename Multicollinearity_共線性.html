多重共線性（Multicollinearity）

一、定義與後果

Multicollinearity 共線性 指模型中的自變數之間存在高度相關性，導致無法精確估計個別自變數對依變數的獨立影響力。技術後果：

  1. 標準誤膨脹：回歸係數的 Standard Error 變大
  2. 檢定力下降：t 值變小，變數即使理論上重要也可能不顯著
  3. 係數不穩定：增刪一個觀察值可能讓係數正負反轉
  4. 解釋失真：難以區分「哪一個自變數真的在驅動結果」

二、典型情境

例題：在使用多元回歸分析探討影響銷售績效的因素時，研究者可能同時放入「總觀看次數」、「按讚數」、「粉絲數」與「平均觀看時長」。 問題：觀看次數、按讚數與粉絲數通常高度正相關（流量大通常讚數也多），這類「流量家族」變數會誘發多重共線性。

三、VIF Variance Inflation Factor 檢測

  • 公式：$VIF_i = 1 / (1 - R_i^2)$，其中 $R_i^2$ 是將第 $i$ 個自變數對其他自變數做回歸所得的判定係數
  • 判斷標準：
門檻 嚴重程度 對應做法
VIF > 10 嚴重共線性 必須處理
VIF > 5 中度警訊 建議處理
VIF > 3.3 PLS-SEM 嚴格門檻 同時觸發 CMB Common method bias Full Collinearity Test 警訊

四、處理策略

  1. 移除變數：刪除相關性過高且理論意義重複的變數
  2. 變數合併：將高度相關的變數組合成複合指標（如：互動指數 = 觀看 + 按讚 + 分享 加權合成）
  3. 降維：以主成分分析（PCA）或因素分析將多個自變數壓縮為少數成分
  4. 逐步回歸：使用 Stepwise Regression 篩選變數（但需謹慎解釋，易過擬合）
  5. 理論層級重整：若兩變數共線，重新檢視是否該以高階潛在構念整合（與 Discriminant Validity 區別校度 處理邏輯相通）

五、與其他效度／偏誤檢定的關聯

  • 與 Discriminant Validity 區別校度 / HTMT：構念層級若 HTMT 偏高（≥ 0.85），結構迴歸內的構念 VIF 通常也會超標。即「測量上難以區分」與「迴歸上彼此淹沒」是同一現象的兩面
  • 與 CMB Common method bias：Full Collinearity Test（Kock 2015）將 VIF < 3.3 同時當作「無嚴重 CMB」與「無嚴重共線性」的雙重證明
  • 與 CFA Marker Variable Technique / Harman's Single Factor Test：若 VIF 高且 Harman 第一因子解釋變異 > 50%，極可能是 CMB 而非真共線性，需以 Marker Variable 進一步診斷

相關概念 - 檢測指標：VIF Variance Inflation Factor - 區別效度：Discriminant Validity 區別校度、HTMT、Fornell-Larcker - 方法偏誤連動：CMB Common method bias、Harman's Single Factor Test、CFA Marker Variable Technique、Lindell Exercise
